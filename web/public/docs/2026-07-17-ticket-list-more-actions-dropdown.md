# 工单列表操作列更多菜单收口

## 变更内容

1. 工单列表操作列默认仅显示详情、编辑、指派、流转和更多按钮。
2. 默认可见按钮改为图标按钮，不再显示文案。
3. 原来的日志、外部跳转、删除按钮收纳到“更多”下拉菜单中，菜单项同时显示图标和文案。
4. 更多菜单复用现有工单日志查看、外部链接跳转和删除逻辑，不改变权限判断与业务行为。

## 影响范围

- `web/src/views/ticket/index.vue`
- `web/src/views/ticket/hooks/useLogViewer.js`
- `web/public/docs/update_history.md`

## 说明

- 详情、编辑、指派、流转按钮仍保留原有权限控制。
- 下拉菜单仅承载原本被隐藏的补充动作，不新增新的业务入口。
