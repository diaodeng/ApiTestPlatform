# 工单日志查看器使用说明

## 入口

日志查看器有两个入口：

1. **工单详情 → 日志拉取 Tab**：在工单详情页点击"日志拉取"标签，可看到该工单的历史日志拉取记录列表。点击任意记录的"查看日志"按钮打开查看器。
2. **工单管理 → 日志拉取记录**：菜单入口独立查看所有日志拉取记录，点击"查看日志"打开查看器。

## 功能概览

日志查看器支持对拉取回来的日志文件进行：关键字搜索、上下文浏览、异常摘要提取、文本高亮和结果导出。

## 一、拉取日志

### 1.1 提交日志拉取

在工单详情页的"日志拉取" Tab 中，点击"新增日志拉取"按钮，填写以下参数：

| 参数 | 说明 | 可选值 |
|------|------|--------|
| 环境 | 日志所在环境 | 从系统参数 `ticket.logPull.external` 配置的环境列表中选择 |
| 商家 | 商家 ID | 可选择或手动输入 |
| 门店 | 门店 ID | 会根据所选商家联动过滤可选范围 |
| POS | POS 机编号 | 手动输入 |
| 数据类型 | 拉取的数据类别 | 命令数据等，取决于环境支持的类型 |
| 拉取方式 | 按时间范围或时间点 | `time`（按时间范围） |
| 时间范围 | 开始时间和结束时间 | 选择日期时间范围 |
| 截取日志 | 是否仅截取时间范围内的日志内容 | 开/关 |
| 存储方式 | 日志保存位置 | `local`（本地） |
| 自动 AI 分析 | 日志成功后是否自动触发 AI 分析 | 开/关，需同时选择 Agent 或 Provider |
| 推送通知 | 成功/失败时是否推送消息 | 开/关，可配置推送渠道 |

### 1.2 日志拉取状态

| 状态 | 含义 |
|------|------|
| `pending` | 等待处理 |
| `processing` | 正在处理中 |
| `polling` | 等待外部平台返回结果（轮询中） |
| `success` | 拉取成功，可查看日志 |
| `failed` | 拉取失败，可查看失败原因 |
| `cancelled` | 已取消 |

有活跃任务（pending/processing/polling）时，列表会每 5 秒自动刷新，直到所有任务进入终态。

### 1.3 操作按钮

- **查看日志**：打开日志查看器（仅成功状态可用）
- **重新拉取**：用相同参数重新提交拉取任务
- **重新下载**：已有压缩包时，重新下载原始文件
- **下载归档**：下载拉取结果的压缩包
- **下载原始**：下载原始未处理的压缩包（如有）
- **删除**：删除该条日志拉取记录

## 二、日志查看器

### 2.1 界面布局

打开日志查看器后，界面分为几个区域：

- **顶部搜索栏**：输入关键字、选择搜索选项
- **左侧/上侧搜索结果区**：显示搜索命中的日志行列表
- **右侧/下侧日志详情区**：显示选中命中行的上下文

搜索和详情两个区域都可以独立全屏（点击对应区域的全屏按钮），`Esc` 键先退出全屏，两个区域都不在全屏状态时再关闭整个弹窗。

### 2.2 关键字搜索

1. 在搜索框中输入关键字，多个关键字用**英文逗号**或**换行**分隔。
2. 选择匹配模式：
   - **任一**：匹配任意一个关键字
   - **全部**：必须同时匹配所有关键字
3. 可选限定：
   - **忽略大小写**：默认勾选
   - **整词搜索**：仅匹配完整单词
   - **文件范围**：下拉多选日志文件，限定搜索范围；不选则全局搜索所有文件
   - **结果上限**：搜索命中条数上限，默认 500
4. 点击"搜索"按钮执行搜索。

搜索结果区域会显示命中的日志行列表，包含日志时间、来源文件和匹配内容。点击任意结果行，右侧详情区会显示该行的上下文。

**二次搜索**：在已有搜索结果的基础上，可以修改关键字或选择特定文件后再次搜索，进一步缩小范围。

### 2.3 上下文浏览

点击搜索结果中的某一行后，日志详情区显示该行的前后上下文：

- **上下文行数**：默认 20 行，可在搜索前调整
- **上一段/下一段**：前后翻页查看更多上下文
- **换行开关**：日志详细信息块的标题区有换行开关。关闭换行时保留原始单行布局，可通过上下文区域底部的横向滚动查看较长日志内容；开启换行时会按可视区域折行，适合快速浏览。
- **超长行展开**：如果某一行内容特别长，查看器会先显示截断后的摘要；点击”展开完整内容”后，在当前行下方打开独立阅读区，支持**全宽**、**全屏**阅读模式和**一键复制**内容，便于查看完整文本。展开后可以继续点击”收起”恢复简洁展示。

### 2.4 异常摘要提取

点击搜索栏右侧的"异常提取"按钮，系统会自动分析当前打开的日志文件，提取其中的异常、错误和警告信息，以摘要形式展示在搜索栏下方。

### 2.5 文本高亮

日志查看器支持两种高亮方式：

#### 搜索关键字高亮
搜索关键字命中的文本会默认高亮显示。

#### 选区高亮
1. 在日志详细信息区选中一段文本
2. 当前上下文中相同的文本会自动高亮
3. 选中的文本会被添加到高亮候选词列表
4. 翻页后高亮关键字保持不变
5. 取消浏览器选区时，临时选区高亮词自动移除

### 2.6 从日志发起 AI 分析

打开日志查看器后，点击搜索栏中的 AI 分析按钮，会默认使用当前日志拉取记录的 ID 作为分析数据源，自动填入拉取记录参数后跳转到 AI 分析流程。

### 2.7 准备进度

当日志尚未准备完成时（如首次打开需要下载和解压），系统会先检查当前记录的准备状态：

- `preparing` 或 `downloading` 状态会直接等待当前任务，不会重复发起下载请求；准备阶段显示 0% 环形进度，远程下载阶段显示实时百分比。
- 查看弹窗关闭不会取消后端准备任务。列表中的“查看日志”按钮会替换为带环形进度的下载中状态，再次打开时继续等待同一任务。
- 工单详情页和“工单管理 → 日志拉取记录”管理页共享同一条记录的进度状态，任一页面都能恢复显示。
- 关闭详情页或刷新后重新进入，列表会从后端恢复正在下载的记录及已下载百分比。进度默认在后端保留约 30 分钟；过期后会重新检查并按实际文件状态处理。

准备完成后自动恢复为正常查看入口，操作列中的复制、重新拉取、重新下载、停止和删除使用图标按钮；将鼠标悬停在图标或进度上可查看提示。

## 三、日志拉取记录管理页

菜单路径：**工单管理 → 日志拉取记录**

该页面展示所有日志拉取记录，支持按以下条件筛选：

| 筛选项 | 说明 |
|--------|------|
| 关联工单 | 按工单编号/标题搜索 |
| 环境 | 按日志环境筛选 |
| 状态 | 按拉取状态筛选 |
| 关键字 | 在工单、异常、摘要、路径中搜索 |
| 商家 | 按商家筛选 |
| 门店 | 按门店筛选 |
| POS | 按 POS 编号筛选 |
| 时间范围 | 按拉取时间范围筛选 |

支持的操作：查看日志、重新拉取、重新下载、下载归档、下载原始、删除。

## 四、AI 分析与日志拉取的关系

工单 AI 分析可以通过两种方式使用日志拉取记录：

1. **从日志查看器发起**：自动带上当前查看的日志拉取记录 ID
2. **从工单详情发起**：未指定记录时，使用该工单最新一条成功的日志拉取记录

AI 分析任务关联日志拉取记录后，Agent 会优先从该记录的日志文件中读取内容。

## 五、常见问题

### Q1: 日志查看器打开后搜索不到内容？

**A**: 检查以下几点：
- 确保日志已准备完成（状态为 `success`）
- 关键字是否拼写正确
- 文件范围是否限制过小（尝试不选文件范围做全局搜索）
- 是否勾选了"整词搜索"导致部分匹配被过滤

### Q2: 准备进度一直在转？

**A**: 先确认后端日志拉取任务和 Redis 可用。关闭弹窗、离开详情页或刷新页面不会取消任务，重新进入后会继续显示后端保存的进度；同一条记录在准备期间再次点击只会等待，不会重复下载。若进度超过约 30 分钟仍未恢复，进度缓存可能已过期，此时重新点击“查看日志”会按当前文件状态重新准备。

### Q3: 搜索结果排序不对？

**A**: 搜索结果默认按日志时间排序，点击"日志时间"表头可在升序和降序之间切换。排序仅处理当前加载的命中结果。

### Q4: 日志拉取失败怎么办？

**A**: 查看失败记录的详细信息，常见原因：
- 日志参数（商家/门店/POS/时间）填写不正确
- 外部日志平台不可用
- 时间范围内没有日志数据

可以修正参数后点击"重新拉取"。
