# Agent 连接使用说明

Agent 页面是桌面客户端与服务端的长连接入口：客户端连接服务端 WebSocket 后，接收工单处理、AI 任务等指令并回传结果。本页说明该页面的功能、入口、配置项与常见问题。

## 页面入口

启动桌面客户端后，点击左侧菜单「Agent」即可进入（该页为主界面默认页之一，常驻显示）。

## 页面布局

页面自上而下分为四个区域：

1. **操作栏**：标题与按钮区，按钮从左到右依次为「清空日志」「服务器管理」「连接设置」「浏览器设置」「连接服务器」「停止」。
2. **地址栏**：展示连接状态徽标、服务器地址下拉框、服务器别名和「显示日志」开关。
3. **状态信息行**：展示连接过程中的动态反馈（如"正在准备连接..."、"连接被拒绝"、浏览器下载进度等）。
4. **日志区**：左右分栏展示「请求参数」与「响应信息」，每栏右上角有「复制」「清空」按钮；顶栏「清空日志」可同时清空两侧。

## 功能与配置说明

### 服务器地址与服务器管理

- **地址下拉框**：可直接输入服务地址（例如 `ws://127.0.0.1:9099/qtr/agent/ws`），也可从已保存的服务器中选择；地址会带别名展示。实际连接地址为「所选地址 + /本机MAC」，由客户端自动拼接，页面不再单独展示。
- **服务器管理**：维护多个服务器（服务名称 + 服务地址），支持新增、修改、删除；上方可填写「配置拉取地址」并点击「更新配置」从服务端拉取客户端配置，同步状态（已同步/未同步及最近同步时间）在同一弹窗展示。
- **别名**：当前所选地址在服务器管理中配置的服务名称；地址不在管理列表中时显示 `-`。
- 连接进行中时，地址下拉框与「服务器管理」按钮会禁用，需先停止再切换。

### 显示日志

控制是否把请求/响应明细写入下方日志区。默认关闭；关闭后已产生的日志保留，仅不再追加。

### 连接设置

点击操作栏「连接设置」打开弹窗，收敛了低频的发送与重连配置：

| 配置项 | 默认值 | 取值范围 | 说明 |
| --- | --- | --- | --- |
| 单条消息上限 | 5 KB | 1 KB ~ 1 MB | 单条发送给服务端的消息最大体积，保存后立即生效 |
| 连接失败后自动重试 | 关 | 开/关 | 主开关，关闭时「重试次数」「重试间隔」禁用 |
| 重试次数 | 0 | 0 ~ 999 | 高频重试窗口的最大次数，0 表示不重试 |
| 重试间隔 | 5 s | 0.1 ~ 3600 s | 高频重试窗口内的重试间隔 |
| 高频重试用尽后低频永续重连 | 关 | 开/关 | 主开关，关闭时「低频间隔」禁用 |
| 低频间隔 | 300 s | 1 ~ 86400 s | 高频窗口用尽后按该间隔持续重连，直到手动停止 |

保存后配置写入本地；重连参数在下次连接或重连时生效。低频永续重连用于服务端发布重启时间过长时客户端仍能自愈上线。

### 浏览器设置

管理 Agent 执行浏览器任务所用的 Playwright 浏览器：自动安装开关、安装目录、下载源、下载代理、三个内核的手动路径，以及手动下载指定内核。详见弹窗内提示文案。

### 浏览器手动下载

在「浏览器设置」弹窗选择目标浏览器后点击「手动下载」，下载进度在页面状态信息行反馈；下载期间按钮禁用。

## 使用步骤

1. 首次使用：进入「服务器管理」，填写配置拉取地址并「更新配置」，或直接「新增」服务器（名称 + ws 地址）。
2. 在地址栏选择要连接的服务器。
3. 如需调整重连策略或发送上限，打开「连接设置」修改并保存。
4. 点击「连接服务器」；状态徽标变为「连接中」「已连接」，状态信息行展示连接过程反馈。
5. 需要断开时点击「停止」。

## 注意事项与常见问题

- **状态徽标含义**：灰色「未连接」、连接中/已连接/断开中为绿色系；以状态信息行的文字反馈为准排查连接失败原因（地址错误、服务端未启动、网络不通等）。
- **连接不上怎么办**：先确认服务地址与端口可通（浏览器访问服务端同主机端口），再确认服务端已启动；若开启了自动重试，客户端会按配置持续重试，无需反复点击「连接服务器」。
- **改了连接设置没生效**：重连参数在下次连接或重连时生效，建议停止后重新连接。
- **找不到 MAC / 完整连接地址**：页面不再展示；完整连接地址 = 服务器地址 + `/` + 本机 MAC，可在服务端连接日志中查看。
- **日志区内容为空**：「显示日志」默认关闭，打开后需重新产生交互才有内容。
