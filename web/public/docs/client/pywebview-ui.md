# 桌面客户端 pywebview 界面（client_new）使用说明

> 适用范围：桌面客户端（client_new）。本文档说明客户端界面由 PySide6 迁移到 pywebview 后的变化：界面布局、功能入口、配置项与注意事项。

## 界面是什么

客户端的图形界面由原来的 PySide6（Qt）桌面窗口迁移为 **pywebview**（系统 WebView2 内核渲染的本地页面）。对使用者来说：

- 仍是一个独立桌面程序，启动方式不变（`uv run python main.py` 或打包后的 exe）；
- 页面布局与原来保持一致：顶部标题栏（版本号、插件按钮、主题下拉）、左侧导航（Agent / POS / SQLite / mitmproxy / 日志 / 关于）、右侧内容区、底部状态栏；
- 所有业务能力（Agent 连接、POS 启停、SQLite 查询、抓包、日志、更新）与迁移前一致，服务层未变。

## 各页面功能与入口

### Agent 页

- **连接控制**：通过「服务」下拉框选择要连接的服务器（选项显示服务名称，不再显示或手输服务地址），点击「启动 / 停止」控制连接；顶部实时显示连接状态、状态消息与本机 MAC；连接过程中（连接中/运行中/断开中）下拉框锁定不可切换，停止后才能更换服务器。
- **服务器管理**：通过「新增 / 修改 / 删除」按钮维护服务器（列表按"服务名称 / 服务地址"两列展示，修改、删除需先在列表中选中一行），配置「配置拉取地址」并可手动触发「同步配置」。
- **连接设置**：自动重试开关、重试次数/间隔、低频永续重连及间隔、单条消息上限。
- **浏览器设置**：Playwright 浏览器自动安装开关、安装目录、下载源、下载代理、各内核可执行路径；支持对 chromium / firefox / webkit 手动下载。
- **请求/响应日志**：勾选「显示请求/响应日志」后，左右两栏实时滚动显示通信报文，可清空。

### POS 页

- **扫描**：点击「工作目录」按钮，在弹窗中维护扫描目录、文件名模式、目录名模式与递归深度，保存后点「扫描」；结果列表支持关键字过滤。
- **每行操作**：启动（启动前会按启动配置依次弹确认框）、打开目录、在线切换、查看环境、本地环境切换、更多（清缓存 / 备份 / 恢复 / 覆盖驱动、清理环境文件、替换证书、退出账号）。
- **启动配置**：备份支付配置、替换 mitm 证书、切换本地环境、切换云端 POS、清除缓存、覆盖支付驱动、退出登录（与启动弹窗联动）。
- **切换POS 弹窗**：环境/商家/门店三级联动，支持指定 MAC 或指定 POS_ID 两种模式，表单状态自动持久化，下次打开自动回填。
- **进程管理弹窗**：按名称过滤系统进程并结束指定进程。
- **退出账号弹窗**：选择环境分组、填写收银员账号，执行退出账号或重置密码。

### SQLite 页

- 先通过「工作目录」维护扫描目录，点击「扫描」发现 SQLite 数据库文件，按目录 → 数据库 → 表三级选择。
- 表数据分页浏览（上一页/下一页/跳转），支持按列快速过滤（包含/等于/大于/LIKE 等）与每页行数设置。
- 「列配置」弹窗控制结果表显示哪些列；配置按"数据库+表"维度记忆。
- SQL 编辑器直接执行 SQL 并展示结果；「常用SQL」弹窗支持按全局/数据库范围保存、载入、删除。

### mitmproxy 页

- 「启动 / 停止」控制本地代理（mitm 内核在独立 helper 子进程中运行）；顶部显示运行状态、模式、流量条数与证书状态。
- 流量表实时滚动，支持按 URL 过滤；点击行在右侧查看请求/响应详情（headers、cookies、form、body）。
- 断点：开启断点拦截后命中的流量会暂停，选中后可「继续放行」或「编辑并放行」（修改 headers/body/状态码后放行）。
- 「设置」弹窗覆盖全部抓包配置（端口、启动方式、SSL、mock、延迟、包含/排除、断点关键字、流量过滤与记录上限等）；运行中修改关键配置会自动重启代理生效。
- 「安装当前用户证书」与「打开 Web 页面」（Web 模式下用系统浏览器打开 mitmweb）。

### 日志页

与原版一致的三个页签：

- **SSH日志**：保留原有连接表单；SSH 实时日志在旧版本即未实现，点击「连接SSH」会给出占位提示。
- **本地日志**：监控任意本地日志/文本文件，与程序日志完全独立：
  - 「选择文件」只负责选中文件并显示路径，**不会自动开始监听**；首次进入会默认选中当前程序日志文件（`logs` 目录当天日志），可直接勾选监听；
  - 勾选「监听日志」后开始实时跟踪选中文件，取消勾选立即停止；
  - 监听中重新选择其它文件会自动切换到新文件继续监听；
  - 支持关键字过滤、最大行数限制（默认 3000 行）、自动滚动。
- **程序日志**：完全监听当前程序自身日志（`logs` 目录下当天日志文件优先，回退最新 `.log`），由独立的「监听日志」开关控制，勾选开始、取消停止，与本地日志的监听互不影响。
- **查看与复制**：两个页签的日志内容均可用鼠标选中后复制（Ctrl+C）；「复制」按钮优先复制选中的文本，无选区时复制当前页签全部内容。

### 关于页

- 显示当前版本、运行形态；「检查更新」展示新版本与 release 说明；「更新」执行自更新（PowerShell 脚本，支持强制更新），下载进度实时显示。
- 版本号旁展示构建信息标签（来源：包内构建时生成的构建信息，源码运行不显示）：正式版显示 tag、commit 与构建时间；开发包显示「开发版」及 commit，若打包时工作区有未提交改动会标注「含未提交改动」，用于追溯包体来源。

### 插件管理（右上角「插件」按钮）

- 查看三个插件（桌面测试 / Web 测试 / 抓包代理）的安装状态；支持在线下载、本地 zip 安装、Pip 安装三种方式。
- 可配置插件包下载源、Pip 源（默认清华镜像）与安装目录。

## 主题

右上角下拉选择「自动 / 浅色 / 深色」：自动跟随系统深浅色设置，选择会持久化。

## 与旧版（PySide6）的差异与注意事项

| 变化点 | 说明 |
| --- | --- |
| 渲染内核 | 界面由系统 WebView2 渲染（Windows 10/11 自带），首次启动如提示缺少 WebView2 Runtime 需安装系统组件 |
| 退出确认 | 关闭窗口不再弹 Qt 确认框，直接退出（退出前自动停止 mitmproxy helper 与 Agent 连接） |
| 确认弹窗 | 业务确认框（如 POS 启动前置检查）由页面模态框承担，超时 5 分钟未响应按「取消」处理 |
| SSH 日志页签 | 旧版「日志」页的 SSH 页签原本就是未实现的占位，迁移后已移除 |
| 桌面录制覆盖层 | Agent 桌面测试的屏幕高亮/框选/批注覆盖层已用 pywebview 透明窗口补齐：录制视口描边为整窗点击穿透（不遮挡自动化操作），录制中可暂停并框选验证区域/忽略区域/新增断言（与原版交互一致） |
| 打包 | 打包 spec 已同步更新（静态资源打入 `ui_web_static/`，移除 Qt 裁剪脚本），主程序不再携带 PySide6 |

## 常见问题

**Q: 页面空白或启动失败？**
查看 `logs/<日期>.log` 与 `logs/fatal_error.log`；前端运行时错误会以「前端js_error / js_rejection」关键字写入应用日志。

**Q: 双击多次启动会开多个窗口吗？**
不会。通过命名互斥体保证单实例，重复启动时会自动把已运行的窗口带到前台。

**Q: 原来的配置还在吗？**
在。所有配置文件（`storage/data/*.json`）与旧版完全共用，无缝沿用。
