# 插件管理（桌面客户端）使用说明

> 适用范围：桌面客户端（client_new）。本文档说明插件化机制：哪些功能依赖插件、如何安装启用、异常时的影响范围。

## 什么是插件

客户端把**体积较大的可选依赖**拆成了插件包，主程序不再内置它们：

| 插件 | 提供的功能 | 包含的依赖 |
| --- | --- | --- |
| **桌面测试** | Agent 桌面测试、桌面自动化录制（图像识别 / OCR / 鼠标键盘控制） | cv2、numpy、pytesseract、pyautogui、pygetwindow、pynput、pillow |
| **Web 测试** | Agent Web 测试、浏览器自动化操作 | playwright（含浏览器驱动） |
| **抓包代理** | 客户端「mitmproxy」页的全部能力：抓包、HTTPS 解密、mock、断点、延迟 | mitmproxy 内核、mitmproxy_rs / windows-redirector（本地按进程拦截）、tornado、aioquic、cryptography 等 |

**未安装插件时，对应功能不可用并会得到明确提示，但主程序与其他所有功能（Agent 连接、POS、SQLite、日志等）完全不受影响。**

### 菜单按插件显隐

左侧导航中「mitmproxy」页依赖**抓包代理**插件：未安装时该菜单项直接隐藏，安装插件并重启客户端后自动出现。其余菜单（Agent / POS / SQLite / 日志 / 关于）不依赖插件、始终显示；Agent 页内的桌面/Web 测试功能在对应插件缺失时会给出安装引导提示。

## 入口

客户端主界面右上角「**插件**」按钮 → 打开「插件管理」对话框。

## 怎么安装

### 方式一：在线下载（推荐）

点击对应插件行的「在线下载」即可，下载源按以下优先级自动选择：

1. **配置了下载源**：在「插件管理」顶部填写**下载源**根地址并保存（由测试平台维护方提供，形如 `https://example.com/qtr-plugins`），客户端从 `{下载源}/{插件名}.zip` 下载，适合内网镜像或私有托管场景；
2. **未配置下载源**：自动从 **Gitee** 定位插件包——优先取与当前客户端版本一致的 release（发版配套、经过一起测试的组合）；该版本未发布 release 或未上传插件附件时，回退到其他 release 中第一个含 `{插件名}.zip` 附件的，安装成功后会提示插件包的实际来源；所有 release 都没有插件附件时弹窗提示原因。

无论哪种方式，若存在 `{插件名}.zip.sha256` 校验文件都会自动做完整性校验；下载与安装在后台执行，按钮置灰防止重复操作，结果以弹窗提示。

**Python 版本兼容校验**：插件包内含编译产物（.pyd），只能运行在构建时的 Python 版本上。新版插件包的 `manifest.json` 记录了构建时的 Python 版本，安装时（在线下载、配置源下载、本地安装均适用）客户端会与当前运行时强校验，不一致直接拒绝安装并说明原因，不会装出无法导入的插件；旧格式插件包没有该字段则跳过校验。

### 方式二：Pip 安装（直接从 PyPI 源安装依赖）

点击对应插件行的「**Pip安装**」，客户端用**内置 Python 运行时**执行 `pip install --target`，把锁版本的依赖清单直接安装到插件目录。适合插件 zip 下载缓慢、或内网环境有私有 PyPI 源的场景。

- **包索引源（Pip 源）**：默认使用国内清华 PyPI 镜像；「插件管理」顶部的"Pip 源"行可自定义（如内网私有 PyPI 源），留空恢复默认；
- **版本锁定**：依赖版本与插件 zip 构建时完全一致（随客户端内置的锁版本清单），不会装到未经测试的新版本；
- **安装结果与 zip 安装完全等价**：装到同一插件目录、补写同样的 manifest，安装失败不影响已装插件；
- **前置条件**：需要客户端目录下存在内置 Python 运行时（`runtime/python`，发版产物默认已包含）；缺失时点击会提示先运行 `scripts/setup_pip_runtime.py` 准备；
- **耗时较长**：需从 PyPI 源下载全部依赖（desktop-test 约 60MB、web-test 约 40MB），超时上限 15 分钟，失败可重试。

### 方式三：本地安装

点击「本地安装」选择已获取的插件 zip 文件（根目录必须包含 `manifest.json`），适合内网环境由维护方分发。

### 安装后

- 插件包解压到插件根目录下的 `<插件名>/` 子目录；**需要重启客户端生效**（插件在启动阶段挂载到模块搜索路径）；
- 状态列显示三种状态：`已启用`（当前可用）/ `已安装，重启客户端后生效` / `未安装`。

### 安装目录

- **默认**：程序目录下 `storage/plugins/`（拷贝整个程序目录即可带走全部插件，绿色便携）；
- **自定义**：在「插件管理」的"安装目录"行修改（可手动输入或点「浏览」选择），保存时页面会展示影响提示，并可选择**把已安装的插件迁移到新目录**（推荐）或仅保存；
- 修改影响要点：新下载/安装的插件放入新目录；自定义目录需自行保证固定可用、不被清理；若目录位于构建输出目录（dist/...）内，重新打包前需先停止 WinDivert 驱动（管理员执行 `sc stop WinDivert`）；
- 恢复默认：清空安装目录输入框后保存即可；历史版本安装位置的插件（旧版 exe 目录 / LOCALAPPDATA）启动时会自动迁移到当前根目录。

### 重新打包注意事项

若打包报 `PermissionError` 指向 `WinDivert64.sys`，说明 mitmproxy 的 WinDivert 驱动仍处于加载状态（用过 local 模式抓包后可能残留）：请先退出客户端并结束 `windows-redirector.exe` 进程，管理员权限执行 `sc stop WinDivert` 后再打包；插件安装目录不在构建输出目录内时通常不会遇到。

## 异常与影响范围

- 在线下载失败（Gitee 所有 release 均无插件附件、网络不通、HTTP 错误、sha256 校验不一致、Python 版本不兼容）：弹窗提示原因并记录日志，**不影响主程序**，可重试或改用本地安装；
- Pip 安装失败（内置运行时缺失、Pip 源不可达、依赖解析失败、超时）：弹窗提示原因并记录日志，不影响主程序与已装插件，可重试或改用其他安装方式；
- 插件包格式不合法（缺 manifest、插件名不符、包含非法路径条目）：拒绝安装并提示；
- 安装中途失败：自动回滚旧版本，已安装的插件仍可用；
- 插件已安装但功能调用报错：Agent 侧收到结构化失败消息（含原因），主界面正常。

## 常见问题

- **桌面测试提示"桌面测试插件未安装或未激活"？** 在「插件管理」安装「桌面测试」插件并重启客户端。另注意 OCR 需要系统已安装 Tesseract（tesseract.exe 在 PATH 中）。
- **Web 测试提示"playwright Python 包未安装（Web 测试插件缺失）"？** 安装「Web 测试」插件并重启；首次使用还需执行浏览器安装（客户端会自动调用 playwright 安装浏览器）。
- **插件包可以装到不同版本的客户端上吗？** 分两种情况：**Python 版本不同则一定不行**——插件包内的编译产物（.pyd）只兼容构建时的 Python 版本，客户端安装时会强校验并拒绝；**客户端版本不同但 Python 版本相同**时技术上可行（如当前版本 release 缺附件时，在线下载会自动回退到其他 release 的插件包，并在安装结果中提示来源），但由于不是发版时一起测试的组合，建议优先使用与客户端版本配套的插件包，跨版本安装后如遇异常请重新下载配套版本。
- **Pip 安装和在线下载怎么选？** 优先「在线下载」（快、体积小、版本完全锁定）；网络到 Gitee/Gitee 附件下载慢、或有内网私有 PyPI 源时用「Pip 安装」；两者都不可用时用「本地安装」。三种方式装出的插件内容等价，可互相覆盖重装。
- **下载源填什么？** 通常无需填写——客户端会自动从 Gitee 下载插件包（优先当前版本配套，缺附件时回退其他版本）。仅在内网无法访问 Gitee、或维护方提供了独立托管地址时才需要配置：企业内网可自行搭静态文件服务，把 `desktop-test.zip`、`web-test.zip`（及可选 `.sha256`）放到该地址根路径下即可。
- **Pip 源填什么？** 留空用默认清华 PyPI 镜像（`https://pypi.tuna.tsinghua.edu.cn/simple`）；企业内网填私有 PyPI 源地址（需能访问到插件依赖包）。
- **想恢复"全内置"的体积优先安装方式？** 主程序已不再内置这些依赖；如需全部功能，把两个插件都安装一次即可。
