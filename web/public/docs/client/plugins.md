# 插件管理（桌面客户端）使用说明

> 适用范围：桌面客户端（client_new）。本文档说明插件化机制：哪些功能依赖插件、如何安装启用、异常时的影响范围。

## 什么是插件

客户端把**体积较大的可选依赖**拆成了插件包，主程序不再内置它们：

| 插件 | 提供的功能 | 包含的依赖 |
| --- | --- | --- |
| **桌面测试** | Agent 桌面测试、桌面自动化录制（图像识别 / OCR / 鼠标键盘控制） | cv2、numpy、pytesseract、pyautogui、pygetwindow、pynput、pillow |
| **Web 测试** | Agent Web 测试、浏览器自动化操作 | playwright（含浏览器驱动） |
| **抓包代理** | 客户端「mitmproxy」页的全部能力：抓包、HTTPS 解密、mock、断点、延迟 | mitmproxy 内核、mitmproxy_rs / windows-redirector（本地按进程拦截）、tornado、aioquic、cryptography 等 |

**未安装插件时，对应功能不可用并会得到明确提示，但主程序与其他所有功能（Agent 连接、POS、SQLite、日志等）完全不受影响。**

### 菜单按插件显隐

左侧导航中「mitmproxy」页依赖**抓包代理**插件：未安装时该菜单项直接隐藏，安装插件并重启客户端后自动出现。其余菜单（Agent / POS / SQLite / 日志 / 关于）不依赖插件、始终显示；Agent 页内的桌面/Web 测试功能在对应插件缺失时会给出安装引导提示。

## 入口

客户端主界面右上角「**插件**」按钮 → 打开「插件管理」对话框。

## 怎么安装

### 方式一：在线下载（推荐）

1. 在「插件管理」顶部填写**下载源**根地址并保存（由测试平台维护方提供，形如 `https://example.com/qtr-plugins`）；
2. 点击对应插件行的「在线下载」；
3. 客户端自动从 `{下载源}/{插件名}.zip` 下载，若服务端提供了 `{插件名}.zip.sha256` 会自动做完整性校验；
4. 下载与安装过程在后台执行，按钮置灰防止重复操作，结果以弹窗提示。

### 方式二：本地安装

点击「本地安装」选择已获取的插件 zip 文件（根目录必须包含 `manifest.json`），适合内网环境由维护方分发。

### 安装后

- 插件包解压到客户端目录下 `storage/plugins/<插件名>/`；
- **需要重启客户端生效**（插件在启动阶段挂载到模块搜索路径）；
- 状态列显示三种状态：`已启用`（当前可用）/ `已安装，重启客户端后生效` / `未安装`。

## 异常与影响范围

- 在线下载失败（地址未配置、网络不通、HTTP 错误、sha256 校验不一致）：弹窗提示原因并记录日志，**不影响主程序**，可重试或改用本地安装；
- 插件包格式不合法（缺 manifest、插件名不符、包含非法路径条目）：拒绝安装并提示；
- 安装中途失败：自动回滚旧版本，已安装的插件仍可用；
- 插件已安装但功能调用报错：Agent 侧收到结构化失败消息（含原因），主界面正常。

## 常见问题

- **桌面测试提示"桌面测试插件未安装或未激活"？** 在「插件管理」安装「桌面测试」插件并重启客户端。另注意 OCR 需要系统已安装 Tesseract（tesseract.exe 在 PATH 中）。
- **Web 测试提示"playwright Python 包未安装（Web 测试插件缺失）"？** 安装「Web 测试」插件并重启；首次使用还需执行浏览器安装（客户端会自动调用 playwright 安装浏览器）。
- **下载源填什么？** 平台维护方提供的插件包托管地址；企业内网可自行搭静态文件服务，把 `desktop-test.zip`、`web-test.zip`（及可选 `.sha256`）放到该地址根路径下即可。
- **想恢复"全内置"的体积优先安装方式？** 主程序已不再内置这些依赖；如需全部功能，把两个插件都安装一次即可。
