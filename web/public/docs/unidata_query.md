# 大数据查询（Unidata）

大数据查询页面用于通过统一凭证托管的方式访问大数据平台（Unidata），在页面内完成数据源切换、权限库/表浏览和只读 SQL 查询。

入口：左侧菜单「大数据」→「大数据查询」（路由 `/bigdata/query`）。

## 功能说明

- **数据源切换**：页面顶部下拉可切换已配置的大数据环境（当前仅 UAT，后续接入 Prod 后在此处增加）。切换数据源后库清单、查询都会走对应环境。
- **库/表/字段树形浏览**：左侧为三级懒加载树——展开**库**显示该库下的表（含中文名），展开**表**显示全部字段（字段名、类型、中文备注）。表清单**分块加载**：每次先加载 200 张，滑到列表底部出现「加载更多表（剩 N）」，点击继续加载，已展开的子树和滚动位置保持不变。悬停表节点会出现「+」按钮，点击可把 `SELECT * FROM 库.表 LIMIT 10` 模板插入 SQL 编辑器。顶部输入框支持按库名过滤，右上角刷新按钮可重新加载库列表。每个库带分层标签：`stable`（含 gray02 共用）、`gray06`、`gray08` 等。
- **SQL 查询**：右侧输入只读 SQL，点击「执行查询」（或编辑器内 `Ctrl+Enter`），下方展示结果列（列名+类型）与数据行，并显示行数、耗时、是否截断。
- **引擎动态探测**：页面加载或切换数据源时，系统会用最小查询（`SELECT 1`）对 Unidata 契约支持的候选引擎（`kyuubi`/`starrocks`）逐一真实探测，**下拉只显示探测可用的引擎**。例如 UAT 未配置 StarRocks 资源时，下拉中只有 `kyuubi（Spark SQL）`；Prod 若已开通 StarRocks 则两个引擎都会出现。探测结果缓存 5 分钟，环境开通新引擎后自动恢复显示。

## 前置配置（管理员一次性操作）

### 1. 统一凭证管理

在「系统管理 → 统一凭证管理」中创建：

1. **凭证**：类型 `API Key`，内容 Header 名称 `Authorization`、值 `Bearer <大数据平台的API Key>`，认证方式「手工录入」。
2. **业务绑定**：业务场景选「大数据查询」（`external_data_query`），投影方式 `HTTP Header`，目标地址/允许域名建议填对应环境域名（如 `uatopen-d.rta-os.com`）。记下**绑定 ID**。

### 2. 系统参数

在「系统管理 → 参数设置」中维护参数键 `unidata.query.sources`（首次访问大数据查询页面时系统会自动创建空配置），值为 JSON：

```json
{
  "sources": [
    {
      "code": "uat",
      "name": "UAT 大数据",
      "baseUrl": "https://uatopen-d.rta-os.com",
      "workbenchCode": "ddw_trade",
      "credentialBindingId": "这里填统一凭证绑定的绑定ID",
      "defaultEngine": "kyuubi",
      "enabled": true,
      "remark": "UAT 环境"
    }
  ]
}
```

参数说明：

| 字段 | 含义 | 说明 |
|---|---|---|
| `code` | 数据源编码 | 页面下拉的值，环境唯一，如 `uat`；接入 Prod 时新增一条 `prod` |
| `name` | 显示名称 | 页面下拉展示 |
| `baseUrl` | Unidata 网关地址 | UAT 为 `https://uatopen-d.rta-os.com`；Prod 接入后填生产域名 |
| `workbenchCode` | 工作台编码 | 如 `ddw_trade`，Unidata runtime 接口必传 |
| `credentialBindingId` | 统一凭证绑定 ID | 填上一步创建的绑定 ID；请求头的 `Authorization` 由该绑定解析 |
| `defaultEngine` | 默认查询引擎 | `kyuubi`（Kyuubi 网关，实际执行引擎为 Spark SQL）或 `starrocks`；当前 UAT 未配置 StarRocks 资源，请用 `kyuubi` |
| `enabled` | 是否启用 | 停用后页面下拉不再展示 |

配置修改后保存即可生效（每次请求实时读取）。

### 3. 菜单

后端启动时自动把「大数据查询」菜单同步到菜单管理（标记 `permission_sync`）。如角色看不到菜单，请在「系统管理 → 角色管理」中为对应角色勾选「大数据查询」菜单。

## 使用步骤

1. 进入「大数据查询」菜单。
2. 顶部确认数据源（UAT）、引擎（自动探测可用项）、最大行数与超时。
3. 左侧展开库 → 表 → 字段（字段名/类型/备注），点击表节点「+」按钮生成查询模板（也可直接手写 SQL）。
4. 点击「执行查询」或 `Ctrl+Enter`，查看结果列与数据行。

## SQL 约束

- **仅支持单条只读查询**：`SELECT` / `WITH` / `EXPLAIN` / `SHOW CREATE TABLE`，多条语句会被拒绝。
- 最大返回行数 10000，超时上限 600 秒（平台侧与 Unidata 侧双重限制）。
- 只能查询**当前账号有权限的表**；无权限表会返回明确错误。
- 个别表即使有权限也可能「数据预览失败」（上游表本身问题），属正常现象，换表即可。

## 注意事项与常见问题

- **下拉里没有数据源**：检查系统参数 `unidata.query.sources` 是否配置、`enabled` 是否为 true。
- **提示“未绑定统一凭证”**：参数中 `credentialBindingId` 为空或填错，请到统一凭证管理的业务绑定列表核对绑定 ID。
- **提示“凭证不可用/目标地址不在白名单”**：绑定的允许域名与 `baseUrl` 域名不一致，调整绑定配置。
- **下拉里没有引擎可选**：说明该数据源当前所有候选引擎探测都不可用（或凭证/域名配置有问题），页面会弹出提示；检查凭证绑定与网络连通性后刷新页面重试（探测结果缓存 5 分钟）。
- **提示“当前公司未配置可用的StarRocks资源”**：引擎下拉不会显示探测不可用的引擎；若通过其他方式提交了不可用引擎，请改用 `kyuubi`。
- **查询很慢**：增大超时秒数（上限 600），或缩小查询范围（加 WHERE / LIMIT）。
- **Prod 环境**：尚未接入；接入时新增凭证 + 绑定（生产域名白名单）+ 在 `unidata.query.sources` 中追加 `code: "prod"` 数据源即可，无需改代码。
