# 工单日志查看器文件列表与 Esc 交互修复

## 背景

日志查看弹窗的文件范围下拉此前只根据当前搜索命中生成。初次打开时下拉为空，搜索后又只能看到命中文件，无法主动切换到同一日志拉取记录中的其他文件。与此同时，日志搜索结果区或日志详情区放大全屏后，按 `Esc` 会直接关闭外层日志查看弹窗。

## 调整内容

1. 日志准备成功后，前端调用 `GET /ticket/logs/files?ticket_id={ticketId}&record_id={recordId}` 获取当前日志拉取记录全部可读日志文件。
2. 文件范围下拉独立保存接口返回的文件路径，保持后端已排序的返回顺序；关键字搜索、异常提取和上下文加载均不会修改该列表。
3. 任一日志子区域处于全屏时，文档捕获阶段优先消费 `Escape` 事件并将全屏区域恢复为普通显示，阻止外层 `el-dialog` 关闭。
4. 两个日志子区域均非全屏时，不拦截 `Escape`，继续使用弹窗原有的关闭行为。

## 影响范围

- 仅影响共享组件 `LogViewerDialog.vue`，工单详情日志拉取页和日志拉取记录管理页会同步获得该交互。
- 不修改后端文件发现、搜索、上下文读取、异常提取或日志拉取记录存储逻辑。

## 验证要点

1. 打开任一已有日志拉取记录，等待准备完成后确认文件范围下拉显示该记录所有文件。
2. 执行全局搜索和单文件搜索后，确认下拉文件数与顺序不变。
3. 分别放大搜索结果区、日志详情区和两个区域后按 `Esc`，确认只恢复区域显示且弹窗仍打开。
4. 两个区域均非全屏时按 `Esc`，确认日志查看弹窗关闭。
