# 问题实例管理

## 功能说明

问题实例用于将确认属于同一个真实问题的多张工单归并管理。工单类型、根因分类和细分问题属于工单分类字段，不会自动替代问题实例归因。

## 绑定工单

进入 **工单管理 → 问题实例管理**，打开问题实例详情，在“绑定已有工单”区域输入工单号或标题进行搜索，选择候选后点击“绑定到当前问题”。页面展示的是业务工单号，不需要输入数据库内部工单 ID。

搜索结果会显示工单号、标题和状态。服务端默认限制返回 20 条候选，并优先按当前 Issue 的项目和模块限制搜索范围。

已绑定工单表会显示：

- 工单号和标题；
- 工单状态（显示状态名称，如“处理中”“已解决”，与工单列表页一致；匹配不到名称时原样显示状态编码）；
- 发生版本；
- 计划修复版本；
- 实际修复版本；
- 实际发版版本；
- 当前处理人和提交时间。

已绑定工单表每行右侧的操作列提供：

- **打开工单**：在新标签页打开系统内的工单详情页；
- **外部地址**：在新标签页打开工单的外部系统详情链接（如 ITSM 工单原始页面）。仅当工单配置了外部链接时显示该按钮，链接与工单列表、工单详情页展示的外部链接一致（优先取工单链接字段，为空时按同步信息兜底）；
- **解绑**：解除该工单与当前问题实例的归因（需要 `ticket:issue:remove` 权限）。

问题详情中的“首张工单”显示业务工单号，点击工单号可以打开工单详情。

## 工单详情关联问题

工单详情的“问题实例操作”区域支持：

- **新建问题实例并绑定**：创建一个新 Issue，并把当前工单作为首张工单；
- **关联已有问题**：按问题编号或标题搜索已有 Issue 后关联；
- **更换问题**：当前工单已有归属时，确认后转移到另一个 Issue；
- **解除归因**：清空当前工单的主问题归属，但不删除 Issue。

相似工单中的“归入同一问题”仍需要人工确认。相似度只提供候选，不会在后台自动绑定。

## 批量关联问题

在 **工单列表** 中先按项目、模块、工单类型、细分问题、根因分类等条件筛选，勾选当前页的工单后点击“批量关联问题”。

操作步骤：

1. 搜索并选择目标问题实例；
2. 检查待关联工单号、标题和当前归属；
3. 填写可选的归因说明；
4. 默认不允许覆盖已归属其他 Issue 的工单；如确需转移，勾选“允许重新归因”并确认；
5. 点击“确认关联”。

批量操作只针对当前页已勾选的工单。后端会先校验全部工单，工单不存在、问题实例不存在、项目不一致或归属冲突时不会产生部分更新。成功后会刷新目标 Issue 和原 Issue 的影响工单数。

## 版本说明

问题实例不保存单一版本。问题详情根据已绑定工单聚合显示四类版本：

- 发生版本：问题在哪个版本发现；
- 计划修复版本：计划在哪个版本处理；
- 实际修复版本：代码实际修复所在版本；
- 实际发版版本：修复实际发布所在版本。

同一个问题可能影响多个版本，因此不能用单个版本号替代绑定工单的版本事实。

## 注意事项

- 默认要求工单和问题实例属于同一项目。
- 批量关联使用人工归因类型，不会为每两张工单创建补充关系。
- 业务工单号用于页面操作，数据库内部工单 ID 仍由系统保存用于稳定关联。
- 负责人不是必填项，新增问题实例时可以不选择负责人；空的可选项目、模块和负责人字段会按未填写处理。
