# 工单第二阶段 Issue 页面入口补齐记录

## 背景

第二阶段的 Issue 归因后端能力已经存在，但此前前端只有工单详情页内嵌的绑定入口，缺少一个独立的“问题实例管理”页面来统一查看、创建、编辑和维护补充关系。

## 本次补齐

1. 新增独立页面 `web/src/views/ticket/issue/index.vue`。
2. 新增前端路由 `#/ticket/issue`，用于进入问题实例管理页。
3. 工单列表页新增“问题实例管理”入口，方便从工单域直接跳转到 Issue 管理视图。
4. 问题实例详情页补齐绑定工单列表、补充关系列表、确认/删除关系和解绑工单能力。

## 页面能力

- 问题实例列表：按编号、标题、状态、项目、模块、负责人和细分问题筛选。
- 问题实例创建/编辑：支持标题、摘要、状态、严重等级、项目、模块、根因分类、细分问题和负责人维护。
- 绑定工单：可将已有工单挂到当前问题实例下。
- 补充关系：可在同一问题实例的绑定工单之间新增、确认和删除补充关系。

## 结果说明

- 后端 Issue 归因能力继续保持不变。
- 前端从“工单详情内嵌操作”补充为“独立管理页 + 详情页内嵌快捷入口”的双入口形态。
- 本次不新增 Issue 统计看板，仍按方案保持第二阶段范围。
