# AI执行审计页面类型中文显示与详情按钮权限修复

## 变更日期

2026-09-01

## 变更概述

修复 AI 执行审计页面（系统管理 → AI执行审计）三个问题：

1. 列表中“任务类型”显示英文原始编码（如下拉只有两个中文选项，其余类型显示英文）。
2. 列表中“来源类型”显示英文原始编码（如 `external_sync_sync_extract`）。
3. 操作列看不到任何按钮（“详情”按钮对所有非超管用户被隐藏）。

## 问题原因

- 前端枚举写死且严重过时：任务类型只配置了 `ticket_translate`、`ticket_knowledge_extract` 两项，而数据库实际已有 5 种以上任务类型；来源类型配置的 4 项与实际写入值完全对不上，导致格式化匹配不到时直接显示英文原值。
- “详情”按钮绑定了 `system:aitaskexecution:query` 权限，但系统菜单中只注册了 `system:aitaskexecution:list`，`query` 权限字符不存在。前端 `v-hasPermi` 指令对无权限用户直接移除按钮节点，因此操作列为空。

## 用户可见变化

- 任务类型下拉与列表显示中文：同步统一提取、翻译、分类统计、自动分类、知识提炼、标题总结、专题分类批次、工单AI分析、向量化Embedding。
- 来源类型下拉与列表显示中文：工单、AI测试、AI分析、飞书专题、批量重分类、手动翻译，以及“场景-动作”格式的同步来源（如“外部同步-统一提取”“多维表格同步-自动分类”）。
- 新增“AI执行审计详情”按钮权限（`system:aitaskexecution:query`），拥有该权限的角色可以在操作列看到“详情”按钮。管理员角色已默认授权；其他角色需要时请在角色管理中勾选“系统管理 → AI执行审计 → AI执行审计详情”。
- 无法识别的新类型仍显示英文原值，不会报错；同步场景拼接来源按“场景-动作”规则自动翻译。

## 涉及文件

- `web/src/views/system/aitaskexecution/index.vue`：补全任务类型/来源类型枚举，新增同步场景拼接来源的规则翻译。
- `server/module_admin/perms.py`：新增 `admin.system.aitaskexecution.query` 按钮权限定义，服务启动时自动同步到菜单表。

## 注意事项

- 后端详情接口（`GET /system/aitaskexecution/{id}`）本来就要求 `system:aitaskexecution:query` 权限，本次只是把缺失的权限定义补上，接口行为无变化。
- 新权限通过启动时权限同步机制落库，已在开发库验证生成菜单记录并授权管理员角色。
