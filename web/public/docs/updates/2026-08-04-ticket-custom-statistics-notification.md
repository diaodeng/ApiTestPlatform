# 2026-08-04 当前系统工单自定义统计通知

## 新增功能

- 在“工单同步配置”新增“自定义统计”页签，可维护多个当前系统工单统计方案。
- 统计支持按提交、创建、首次响应、形成结论、处置完成或关闭时间限定今天、昨天、最近 N 天、自然周或固定范围。
- 支持项目、模块、模块编码和工单类型范围过滤；可按字段原值分组，也可使用安全条件规则归类。
- 通知支持系统推送配置、飞书应用群消息或两者同时发送；可配置文本模板或飞书卡片，并按需附带少量最新工单明细。
- 新增手动试运行入口和定时任务 `module_task.scheduler_maintenance.ticket_custom_statistics_report`。

## 使用提醒

- 统计结果不写入统计快照表，因此重跑同一历史时间段时会读取工单当前字段状态。
- “是否有结论”建议用 `processed_at` 是否为空配置，不建议只按流程状态判断。
- 单个统计方案最多扫描 50,000 条工单；超过上限应收窄时间范围或增加模块、类型等过滤条件。

完整字段与配置说明见 [工单同步自动化说明](../ticket-sync-automation.md)。
