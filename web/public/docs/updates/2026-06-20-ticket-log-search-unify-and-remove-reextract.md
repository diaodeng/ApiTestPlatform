# 2026-06-20 工单日志搜索收敛与重新截取入口移除

## 结论
- “按时间搜索”本质上只是按固定时间文本做关键词匹配，和普通关键词搜索没有独立能力，已从当前日志查看弹窗移除。
- 当前工单日志查看链路中的“重新截取”按钮已移除，不再和统一日志查看器混用。
- “重新拉取”和“重新下载”仍保留，且仍然可以正常对接日志拉取记录链路。

## 说明
- 后端 `LogService.search_time(...)` 只是直接调用 `search(ticket_id, time_keyword, ...)`，没有单独的时间索引或时间语义解析。
- 因此前端保留两个入口只会增加重复操作，改为只保留一个关键词搜索入口。
- `重新截取` 依赖的是日志拉取记录的原始时间范围，不属于当前统一日志查看器的核心职责；在当前页面里移除后，能减少误用和上下文错配。

## 保留能力
- `重新拉取`：
  - 仍按日志拉取记录 `recordId` 重新提交拉取任务。
  - 不依赖当前查看器状态。
- `重新下载`：
  - 仍按日志拉取记录 `recordId` 重新下载归档文件。
  - 仍可与当前日志查看器配合使用。
