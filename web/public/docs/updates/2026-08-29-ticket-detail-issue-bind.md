# 独立工单详情页支持关联问题实例

- 变更日期：2026-08-29
- 变更范围：工单管理 → 独立工单详情页（`/ticket/detail/{ticketId}`）。

## 变更内容

- 独立工单详情页顶部标题栏新增 **关联问题实例** 按钮（位于刷新按钮左侧），可在详情页内直接将当前工单归因到指定问题实例，无需回到工单列表使用批量关联。
- 按钮文案随状态变化：无问题归属时显示 **关联问题实例**；已有时显示 **更换问题实例**。
- 弹窗内提供目标问题实例远程搜索（按问题编号或标题，限定当前项目/模块）、归因类型、已确认开关和归因说明。
- 已有问题归属时，弹窗顶部展示"当前已归属问题"提示条，并预填当前问题与归因类型、确认状态；换绑到其他问题时需二次确认。
- 按钮受 `ticket:issue:bind` 权限控制，无权限时按钮不显示。

## 使用说明

1. 打开独立工单详情页（例如从工单链接、相似工单的"系统详情"进入）。
2. 点击顶部 **关联问题实例**（或 **更换问题实例**）按钮。
3. 在弹窗中搜索并选择目标问题实例，按需调整归因类型与确认状态，可选填写归因说明。
4. 点击 **确认关联**；换绑场景需在二次确认弹窗中确认。
5. 提交成功后弹窗关闭，详情自动刷新，问题归属信息同步更新。

## 技术说明

- 前端组件：`web/src/views/ticket/components/TicketDetailView.vue`，交互与工单列表内嵌详情的"关联已有问题实例"保持一致。
- 后端接口：复用既有单工单绑定接口 `POST /ticket/{ticket_id}/issue/bind`（`TicketIssueService.bind_ticket_to_issue`），未新增或修改任何后端接口；同一工单重复绑定同一问题实例幂等成功，关联成功后自动刷新新旧问题实例的影响工单数。

## 注意事项

- 服务端会校验工单与问题实例属于同一项目，跨项目的问题实例无法关联。
- 该按钮仅控制入口显隐，实际操作仍受后端 `ticket:issue:bind` 接口权限校验。
