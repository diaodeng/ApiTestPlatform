# 工单 AI 分析 Agent 跨进程派发与并发队列

## 变更内容

- 新增 AI 配置中心字段 `Agent 并发数`，用于控制单个 Agent 同时允许执行的重型 AI 任务数量。
- AI 分析任务不再直接依赖进程内 websocket 连接表，而是通过 FastAPI 内部网关 `/qtr/agent/ai-analysis/send/{agent_code}` 进行跨进程派发。
- 当单个 Agent 的并发数达到上限时，后续任务会进入队列等待，不会立即失败。
- 队列等待超过任务总超时时，任务会按失败终态落库，并写入明确原因。

## 影响范围

- 系统管理 → AI配置中心
- 工单自动 AI 分析
- 日志拉取后的自动 AI 分析

## 使用建议

- 生产环境默认建议保持 `1`，确认 Agent 稳定后再逐步提高。
- 如果 Agent 断连较频繁，优先降低并发数，避免同时占用多个任务槽位。
