# 2026-09-05 - 工单详情 AI 翻译默认收起与相似工单操作按钮布局调整

## 变更背景

工单详情页存在两个展示体验问题：

1. 原文和 AI 翻译默认全部展开，打开详情时大段译文抢占首屏，原文反而被推到很靠下的位置。
2. 相似工单条目的操作按钮（系统详情 / 飞书详情 / 归入同一问题）竖排在条目右侧，当详情弹窗或页面宽度较小时，右侧按钮列占位导致左侧标题和命中信息被挤压换行，而按钮列右边留大片空白，布局观感很差。

## 变更内容（仅前端，两个组件）

### 1. AI 翻译默认收起

`web/src/views/ticket/components/detail-shared/TicketDescriptionBlock.vue`：

- 译文区块默认收起，只显示"AI翻译"标题行和"展开"按钮；原文仍默认展开。
- 切换工单后同样重置为译文收起。
- 该组件同时用于独立详情页和列表详情弹窗，行为一致。

### 2. 相似工单操作按钮移到内容下方

`web/src/views/ticket/components/detail-shared/TicketSimilarPanel.vue`：

- "工单内容相似"和"处理案例相似"两个卡片的条目均由"左内容 + 右按钮列"改为上下结构：标题、相似度/模块/状态、命中与冲突信息、操作按钮自上而下排列，按钮独占一行并跟随内容左对齐。
- 按钮顺序和功能不变：系统详情、飞书详情（有外链时）、归入同一问题（有权限时）。
- 按钮行允许换行（flex-wrap），窄屏下不再与标题争抢横向空间。

## 影响范围

- 工单列表详情弹窗、独立详情页（`/ticket/detail/:ticketId`）的描述与翻译展示。
- 概览 tab 与"相似工单"tab 的相似面板（共用同一组件）。
- 无后端改动、无接口变更、无权限变更。
