# 帮助文档自动索引说明（2026-06-28）

## 背景

帮助中心页面原先在 `web/src/views/about/about.vue` 中手写菜单，只能看到固定的几篇文档。后续业务说明、配置说明和排障说明虽然持续写入 `web/public/docs`，但没有自动入口，用户和开发者都不容易找到最新用法。

## 本次调整

1. 新增 Vite 文档索引插件，开发服务启动和生产构建时自动扫描 `web/public/docs` 下的 Markdown 文件。
2. 扫描结果写入 `web/public/docs/docs-index.json`，帮助中心页面读取该索引生成菜单。
3. 帮助中心新增搜索框，可按标题、文件名和分类搜索。
4. 文档按用途自动分类，常见分类包括：
   - 首页与入门
   - 接口测试基础
   - 工单同步与多维表格
   - 工单日志与分析
   - AI 与智能配置
   - 通知提醒与消息
   - 业务说明
   - 配置说明
   - 更新记录
5. 常用文档保留在“常用入口”，用户说明按功能和模块展示，`web/public/docs/updates/` 下的更新记录单独分组显示，避免新文档只能通过手工改菜单出现。

## 后续新增文档规则

1. 用户说明文档优先放到 `web/public/docs` 的功能或模块目录下，文件扩展名使用 `.md`。
2. 用户说明必须尽量完整，至少写清楚功能是干什么的、入口在哪里、怎么使用、有哪些配置项、每个参数的含义、默认值、可选值、不同取值的影响、示例、注意事项和常见问题。
3. 如需更明确的菜单标题，也可以在 Markdown 顶部写 frontmatter：

```markdown
---
title: 工单同步自动化说明
---
```

4. 更新记录统一放到 `web/public/docs/updates/` 独立目录，建议使用日期前缀命名，例如：

```markdown
2026-08-03-ticket-docs-structure-rules.md
```

5. 新增或修改文档后，重新启动前端开发服务或执行生产构建，`docs-index.json` 会自动更新。
6. 修改业务逻辑时，如果没有对应的用户说明文档，必须先补齐后再交付。

## 注意事项

- 浏览器不能直接枚举 `public/docs` 目录，所以必须依赖构建期生成的 `docs-index.json`。
- 如果帮助中心提示索引加载失败，会回退显示基础文档，但新增文档不会自动出现。
- `docs-index.json` 是自动生成文件，不建议手工维护。
- 更新记录虽然也放在 `web/public/docs` 下，但应该通过 `updates/` 目录与用户说明分离，避免在帮助中心混排。
