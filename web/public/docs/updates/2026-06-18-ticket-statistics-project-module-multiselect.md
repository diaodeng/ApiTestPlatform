# 工单统计项目与模块多选筛选

## 背景

工单统计页原来只支持按创建时间范围筛选，无法在同一页面对指定项目或模块做统计切片。

## 调整内容

1. 工单统计页顶部新增“项目”和“模块”筛选。
2. 项目支持多选、搜索、清空。
3. 模块支持多选、搜索、清空；未选择项目时展示全部有效模块，选择一个或多个项目后只展示所选项目下的模块。
4. 项目切换后会自动移除不属于当前项目候选范围的模块选择，避免提交无效模块 ID。
5. `GET /ticket/statistics/overview` 新增 `projectIds` 和 `moduleIds` 查询参数，支持逗号分隔多选 ID。
6. 后端统计总数、状态、分类、模块、人员、来源、优先级、RCA 和流转次数均使用同一组项目/模块过滤条件。
7. 统计接口的同步数据库聚合查询改为在线程池中执行，避免阻塞 FastAPI 事件循环。
8. 工单列表页的模块筛选同步使用同一规则：未选择项目时可选择全部模块，选择项目后只展示当前项目下的模块。

## 接口参数

```text
GET /ticket/statistics/overview?beginTime=2026-06-01&endTime=2026-06-18&projectIds=1,2&moduleIds=10,11
```

## 影响范围

- 工单模块选项接口未传项目 ID 时会返回全部有效模块；工单列表页和统计页都会使用该规则。
- 仅影响工单列表页、工单统计页、模块选项接口和统计接口。
- 不改变工单列表、工单详情和同步自动化统计通知。
