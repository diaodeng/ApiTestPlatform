# 更新记录：工单详情日志拉取 Tab 操作列改为主次分离布局

- 日期：2026-09-01
- 类型：体验优化
- 模块：工单详情 → 日志拉取 Tab

## 变更内容

与"日志拉取记录管理页"保持一致，工单详情页日志拉取 Tab 的操作列从"6 个彩色圆形按钮平铺"改为主次分离布局：

- 查看日志：常显文字链接（下载中仍显示环形进度）。
- 重新拉取：常显的高频主操作，按钮不再依赖行悬浮显示。
- 复制新建、停止任务、重新拉取、重新下载：统一收纳到常显的「更多」下拉菜单，保留原有禁用态语义（执行中不可复制/重试/删除、停止仅执行中可用、重新下载需有归档）。
- 删除：下拉菜单内用分隔线隔离、红字置底，删除前仍走二次确认。
- 操作列固定为 220px 并固定在表格右侧，确保常显按钮完整显示。
