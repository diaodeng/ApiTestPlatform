# 2026-09-14 桌面客户端 POS 列表优化（操作列宽度/图标按钮/环境信息行/复制路径）

## 背景

用户反馈 POS 页列表五点问题：

1. 操作列右侧空白区域太大，希望操作列按内容多少决定宽度；
2. POS 路径列希望按迁移前的方式展示，包括「本地环境」操作后左侧列信息动态更新（旧版每行左侧有环境信息行，查看环境/切换环境后实时刷新）；
3. 操作列按钮希望换成图标按钮（旧版 PySide 即为图标按钮）；
4. 「更多」菜单缺少迁移前的「复制路径」项；
5. 左侧路径需要支持选中复制。

## 变更内容

### `client_new/ui_web/static/js/core.js`

- 新增零依赖内联 SVG 图标工具 `icon(name, size)` 并导出：路径数据取自 Feather Icons（MIT），`currentColor` 跟随文字颜色自动适配主题；内置 `play/folder/refresh/info/home/copy/more` 七个图标，`more`（竖排圆点）按实心渲染。

### `client_new/ui_web/static/css/app.css`

- 新增 POS 列表专用样式（作用域限定 `.pos-table`，不影响其它页面的 `table.data`）：
  - 操作列按内容收缩：`th:last-child, td:last-child { width:1%; white-space:nowrap }` 标准贴内容写法，剩余空间全部留给路径列；
  - 路径单元格局部放开 `user-select: text`（全局 body 为 `none`），支持鼠标选中复制，光标显示为文本态；
  - 环境信息行样式：默认弱化色，获取中用主题色高亮（对齐旧版 PySide 行为）；
  - 图标按钮 `.btn.icon-btn`：紧凑内联布局。

### `client_new/ui_web/static/js/pages/pos.js`

1. **操作列图标化**：启动/打开目录/在线切换/查看环境/本地环境/更多六个按钮改为内联 SVG 图标按钮，语义通过 `title` 悬停提示保留；移除操作容器 `flex-wrap`（图标化后单行足够，不再换行）。
2. **左侧列环境信息行动态更新**（对齐旧版）：
   - 路径单元格两行：第一行完整路径，第二行环境信息，初始显示「环境: 未获取」；
   - 点击「查看环境」先显示「环境: 获取中...」（主题色高亮），完成后按旧版 `_format_env_message` 格式回填摘要：`{本地|远端} 商家:x | 门店ID(sap/org): x/x | 环境:x 版本:x POS:x`（含商家与门店信息）；信息行已展示完整摘要，**查看环境不再弹出信息弹窗**，日志区同步留档；
   - 「本地环境」切换成功后自动重新获取环境信息并刷新左侧列（旧版未做、本次补齐），同时自动关闭切换弹窗；
   - 状态按 POS 路径用 `Map` 记忆，列表过滤/重扫描重渲染后保留已获取的结果。
3. **更多菜单补「复制路径」**：菜单底部以分隔线隔开新增「复制路径」项（纯前端 `copyText`，不走后端），对齐旧版菜单。
4. **双击路径复制**：双击路径单元格复制完整路径（对齐旧版 PySide 双击复制交互），复制成功有 toast 提示。
5. **底部状态区改造**：
   - 状态文本支持鼠标选中复制（app.css 新增 `.selectable` 工具类）；
   - 点击「停止POS」后状态区以停止结果为准（「POS已停止」/「没有运行中的POS」），不再保留之前 POS 的运行信息；
   - 状态行新增「收起/展开」按钮，可整体显示或隐藏运行状态文本与日志面板，按钮本身保持可见。
6. 表格增加 `pos-table` 类名以承载上述专用样式；查看环境弹窗移除后清理了未使用的 `kvTable` 引用。

## 验证

- `node --check` 通过（core.js、pos.js）；
- 未做 GUI 实机验证（需要运行客户端环境），建议启动客户端后确认：操作列贴内容收缩、悬停图标显示提示、查看环境/切换本地环境后左侧列实时刷新、更多菜单与双击复制路径生效。

## 遗留与建议

- 环境信息摘要由前端 `get_env` payload 拼装，完整字段仍在「查看环境」弹窗键值表中；
- 若后续其它页面也需要图标按钮，可直接复用 `window.QTR.icon`，无需引入图标库。
