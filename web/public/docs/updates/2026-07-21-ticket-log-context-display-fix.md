# 工单日志详情上下文不显示修复

## 问题

工单详情页的日志查看器完成关键字搜索后，上下文接口已返回 `lines` 数据，但 Chrome、Edge 等支持 CSS Highlight API 的浏览器中，日志详细信息区域为空。

## 根因

`TicketDetailLogPullTab.vue` 在原生高亮分支将每一行的 `parts` 设置为空数组。模板依赖 `parts` 输出日志正文，导致虽已拿到上下文数据却没有生成文本节点；原生高亮的 `Range` 也无法绑定到任何内容。

## 修复

原生高亮分支改为输出一个未拆分的普通文本片段，并通过 `TreeWalker` 扫描其后代文本节点。浏览器继续通过 CSS Highlight API 对该文本节点覆盖高亮，不会重建为多个 `mark` 节点，且日志正文能够正常显示和复制。

## 验证

1. 在 Chrome 或 Edge 的工单详情页打开日志查看器并搜索关键字。
2. 点击任一搜索命中，确认详细信息区域显示上下文行。
3. 输入或选中高亮文本，确认正文仍可显示且高亮、复制功能正常。
