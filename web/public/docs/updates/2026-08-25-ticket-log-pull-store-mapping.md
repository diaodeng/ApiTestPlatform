# 2026-08-25 自动日志门店映射修复

- 修复外部多维表格同步自动拉日志时，将原始 `sourceStoreCode`（例如 SAP 门店编码）直接作为日志接口 `storeId` 的问题。
- 自动日志现在优先使用字段识别阶段按商家门店配置映射得到的 `org_no`；`sourceStoreCode` 继续只保存外部原始值，不会被覆盖。
- 增加自动日志参数不完整时的明确告警日志，记录工单号、同步场景和最终运行参数，便于区分参数校验跳过与外部接口失败。
- 对同一商家、同一 SAP 或其他外部门店编码命中多个不同 `org_no` 的情况，停止按最新修改时间静默选择；自动日志会记录全部候选门店并跳过提交，避免日志落到错误门店，需人工消歧后再执行。
- 对应工单的生产审计曾显示 `vendorId=11、sourceStoreCode=1272、storeId=1272`，其中 `1272` 是 SAP 编码，映射后的日志接口门店应为合法 `org_no`（如 `552283`）。本次仅修改代码和文档，未写入生产数据库。
