# 2026-08-06 统一凭证管理优化

- 统一凭证页面调整为“凭证 / 业务绑定”两个标签页，移除日志拉取外部环境可视化配置。
- 日志拉取外部环境继续通过系统参数 `ticket.logPull.external` 配置；环境只填写 `credentialBindingId`，不填写 Cookie、Authorization 或 API Key。
- 业务绑定增加回写开关和投影组合校验；新增浏览器 `storageState` 版本安全回写接口，普通 Web 执行仍默认只读。
- 已部署首版凭证表的环境需执行 `server/sql/20260806_credential_binding_writeback.sql`，补充业务绑定回写开关字段。
- 修复凭证新增、更新、删除接口的鉴权日志 500：接口数据库会话参数统一使用 `query_db`，与系统日志装饰器约定保持一致。
- 补齐凭证配置页面的登录/刷新参数：支持用户名、密码、TOTP、请求 Header/查询参数/JSON 或表单请求体，以及响应 JSON、响应头和 `Set-Cookie` 提取规则。
- HTTP 刷新请求会自动携带现有 Cookie/Header，手工录入且没有账号密码的凭证也可以通过刷新接口自动续期；刷新结果按版本安全合并，失败保留旧快照。
- 敏感内容改为按凭证类型分区填写，编辑时不回显密文；认证请求模板中的固定敏感字段在详情响应中脱敏。
- 修复旧凭证认证配置中新增 JSON 字段为 `NULL` 时无法进入凭证管理页面的问题；读取时统一按空对象或空列表处理。
