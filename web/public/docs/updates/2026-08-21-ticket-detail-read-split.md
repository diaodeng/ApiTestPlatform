# 2026-08-21 - 工单详情首屏读取拆分

## 用户可见变化

- 工单列表打开详情时，先展示轻量主概览，不再等待消息、快照和相似工单全部返回。
- 相似工单改为独立区域加载，等待期间显示 loading；没有结果、向量生成中或查询失败时显示明确状态。
- 协同/AI 标签按需读取最近消息和 ACR 快照，默认分别为 20 条和 10 条，单次最多 100 条。
- 快速切换工单时会清空上一张工单的数据，旧请求返回不会覆盖当前工单。
- 关闭详情后会停止日志自动刷新、日志准备进度查询和 AI 任务短轮询，并清理日志查看器状态。

## 兼容说明

- 原有完整详情接口 `GET /ticket/{ticket_id}` 和旧消息接口 `GET /ticket/{ticket_id}/messages` 保留，其他入口可以继续使用。
- 新增读取接口的 BIGINT 主键以字符串返回，前端无需将这些 ID 转换为 JavaScript Number。
