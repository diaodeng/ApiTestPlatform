# 更新记录：日志拉取记录管理页操作列改为主次分离布局

- 日期：2026-09-01
- 类型：体验优化
- 模块：工单管理 → 日志拉取记录

## 变更内容

操作列从"6 个彩色圆形图标按钮平铺（270px 宽）"改为主流中后台的「主次分离 + 折叠收纳」布局：

- 查看日志：常显文字链接（下载中仍显示环形进度）。
- 重新拉取：行悬浮时显示的高频主操作。
- 复制新建、停止任务、重新拉取、重新下载：统一收纳到常显的「更多」下拉菜单，保留原有禁用态语义。
- 删除：下拉菜单内用分隔线隔离、红字置底，删除前仍走二次确认。
- 操作列宽度 270px 收敛为固定 170px，并固定在表格右侧。
