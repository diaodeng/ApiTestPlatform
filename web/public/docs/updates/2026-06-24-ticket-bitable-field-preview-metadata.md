# 2026-06-24 多维表格主动拉取字段预览修复

## 背景

主动拉取的运行查询已下推默认时间窗口到飞书 `records/search` filter。字段映射区的“读取表格字段”原先复用查询一条记录的逻辑，最近一小时或当前过滤条件下没有记录时会返回 `records=0`，导致字段下拉为空。

## 改动

1. 后端字段预览优先调用飞书多维表格字段元数据接口读取字段名，不再依赖样例记录。
2. 字段元数据读取失败时，回退到样例记录推断字段，但会清空 `filterFormula` 和 `createdAfter`，避免被主动拉取运行过滤条件影响。
3. 页面文案改为说明“读取表格字段”读取字段元数据，不受主动拉取过滤条件和时间窗口影响。

## 影响范围

1. 影响接口：`POST /ticket/sync/automation/bitable-pull/fields-preview`。
2. 不改变定时任务 `module_task.scheduler_maintenance.pull_feishu_bitable_ticket_sync` 的真实拉取过滤逻辑。
3. 不改变字段映射保存结构，仅改善字段候选读取能力。

## 验证

1. 新增单元测试覆盖字段元数据读取路径。
2. 新增单元测试覆盖元数据读取失败后回退样例记录且不携带过滤条件。
