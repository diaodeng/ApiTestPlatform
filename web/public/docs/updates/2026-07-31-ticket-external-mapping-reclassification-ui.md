# 工单批量映射归类入口

## 背景

后端批量重归类接口已支持 `strategy=external_mapping`，可依据工单在外部同步时保存的原始字段快照重新匹配工单类型映射规则，但同步自动化页面此前只展示“AI归类”和“正则归类”。管理员无法从页面直接发起映射重归类，也容易误以为正则规则为空时会自动改走映射。

## 本次调整

1. 同步自动化页“自动分类管理”的归类策略新增“映射归类”。
2. 选择“映射归类”时，页面明确提示其数据来源、不会调用 AI，以及人工确认类型的默认保护规则。
3. 映射策略提交时不再携带 AI 提示词；正则规则仍只在选择正则策略时提交。
4. 正则策略未配置规则时保持现有“未配置正则归类规则”跳过语义，不增加隐式映射；已配置规则但未命中时，保持既有 AI 兜底行为。

## 使用规则

| 策略 | 数据来源 | 未命中处理 | 是否调用 AI |
| --- | --- | --- | --- |
| AI归类 | 标题、描述、评论及统计上下文 | 返回 AI 无结果或跳过原因 | 是 |
| 正则归类 | 标题、描述与页面输入的正则规则 | 规则为空时返回“未配置正则归类规则”；规则未命中时保持既有 AI 兜底 | 规则未命中时是 |
| 映射归类 | `extra_data.external_field_mapping`、`raw_payload` 与系统字段映射配置 | 返回“未命中外部字段映射规则” | 否 |

映射归类默认跳过 `classification_source=manual` 的工单；只有用户显式勾选“强制覆盖已有分类”时，才允许映射结果覆盖人工类型。

## 影响范围

- 前端：`web/src/views/ticket/syncAutomation/index.vue`
- 既有接口：`POST /ticket/sync/auto-category/reclassify`
- 后端无需新增接口或调整数据库结构。

## 验证建议

1. 在“系统字段”配置至少一条外部字段到工单类型的映射规则。
2. 选择“映射归类”，指定一张具有已保存外部字段快照的工单执行。
3. 验证命中时工单类型、分类来源和命中审计被更新；未命中时返回明确跳过原因。
4. 对人工确认类型分别验证未勾选、勾选“强制覆盖已有分类”两种行为。
