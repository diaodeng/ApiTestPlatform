# 2026-08-08 工单日志查看器搜索结果列宽拖拽修复

## 修复内容

修复工单日志查看弹窗中，搜索结果列表的列宽拖拽手柄不显示、鼠标不显示左右拖动状态、按住后无法调整列宽的问题。

现在“文件”“行号”和“日志内容”表头右侧会始终显示竖向分隔线；将鼠标移到分隔线附近时会显示左右拖动光标，按住后可调整当前列宽。

分隔线已调整为紧凑的 1px 细线，实际拖拽热区保持 12px 宽；手柄改为绝对定位，不会再撑高表头，表头保持虚拟表格默认的 44px 高度。

## 影响范围

- 工单详情页的日志查看弹窗。
- 工单日志拉取记录管理页的日志查看弹窗。

## 注意事项

- 该修复调整的是前端样式和指针事件处理。若使用已部署的前端静态资源，需要重新构建并发布前端资源后才会生效。
- 关闭日志查看弹窗或打开另一条日志拉取记录后，列宽仍会恢复为默认值。
