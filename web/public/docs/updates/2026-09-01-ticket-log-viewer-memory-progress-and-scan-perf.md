# 日志查看器内存分析：完成态图标与扫描性能优化

- 变更时间：2026-09-01
- 影响模块：工单日志查看器 - 内存分析

## 变更内容

1. **解析完成态展示修复**：此前进度条被限制在 99%，解析完成后进度区直接隐藏，看不到"成功"状态。现在解析完成后进度条定格 100% 并显示成功图标（对勾），同时提示"内存分析完成，共提取 N 条监控数据"和总耗时，约 1.5 秒后自动切换为图表；点击"刷新"或"关闭"会立即清掉完成态。
2. **扫描性能优化**：内存分析逐行扫描日志时，新增 `Process cpu` ASCII 字节锚点预过滤——只有包含该锚点的行才做 UTF-8 解码和正则匹配，其余行直接跳过。由于监控行在日志中占比极低，大文件扫描的 CPU 开销显著下降，解析结果与原有正则完全一致。

## 同日追加修复

- 修复图表空白问题：新增"完成态"后，结果返回时图表组件尚未挂载（成功态停留期间），`watch` 触发时画布 DOM 不存在导致渲染被跳过，1.5 秒后组件挂载但不会再触发渲染，画布永远空白。已在 `LogMemoryChartPanel` 的 `onMounted` 中补充"数据已就绪则主动渲染一次"，覆盖"数据先到、组件后挂载"的场景。

## 说明

- 顶部按钮的"刷新"仍带 loading 转圈，本次新增的是进度条自身的完成态图标，两者互不影响。
- 扫描实现为 Python 逐行读取 + 字节锚点预过滤 + 编译正则，未引入 grep/ripgrep 等外部进程依赖，跨平台行为一致。
