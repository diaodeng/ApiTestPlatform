# 2026-08-21 - 工单问题实例关联增强

## 新增

- 问题实例页面支持按工单号或标题搜索并绑定工单，不再要求用户输入数据库内部工单 ID。
- 问题实例详情中的首张工单改为显示业务工单号。
- 工单详情页新增“关联已有问题”和“更换问题”操作，可直接按问题编号或标题搜索。
- 工单列表新增“批量关联问题”，支持将当前页选中的多张工单归入指定问题实例。
- 问题实例绑定工单表增加发生版本、计划修复版本、实际修复版本和实际发版版本展示。

## 规则

- 相似工单只作为归因候选，仍需人工确认，不会因为相似度或工单类型自动强绑定。
- 批量关联默认不会覆盖已经归属其他问题实例的工单；只有显式允许重新归因并二次确认后才会转移。
- 批量接口先校验全部工单，再在一个事务中更新，校验失败不会产生部分关联。
- 批量操作只作用于当前页已选择的工单。
- 工单和问题实例默认必须属于同一项目。

## 影响范围

- 工单问题实例管理页面
- 工单详情页
- 工单列表页
- 问题实例归因接口与工单事件时间线
