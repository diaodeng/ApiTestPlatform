# 2026-08-21 - 工单列表提交时间与性能索引调整

## 用户可见变化

- 工单列表和详情中的“工单提交时间”以工单业务提交时间为准，不再以外部同步记录时间或本地创建时间替代显示。
- 按提交时间筛选和排序与列表、详情显示使用同一时间口径，避免查询结果顺序与显示时间不一致。

## 性能说明

- 默认列表按提交时间排序时可使用工单提交时间索引，减少读取和排序开销。
- 模块业务码筛选、日志拉取进度和 AI 分析进度的查询索引已在系统模型中声明。生产数据库需由运维执行对应索引创建后生效。

## 兼容说明

- 外部同步来源时间继续作为同步记录保留，用于追溯来源；它不再参与工单列表的提交时间筛选、排序或显示。
- 已保存的工单业务提交时间不会被本次调整修改。
