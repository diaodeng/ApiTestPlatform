# 工单自动日志去重与任务 TID

## 变更时间

- 2026-08-26

## 变更内容

1. **自动日志去重**
   - 同一工单下，如果自动化计算出的日志拉取参数与历史某条**成功**记录一致，系统不再重复向外部平台发起相同日志申请。
   - 本次自动化会直接复用该成功记录，并把“已复用成功日志”写入自动化审计。

2. **自动 AI 复用成功日志**
   - 如果这次没有重新拉日志，但工单下已经存在最近一次成功日志记录，系统也会直接复用该记录继续执行自动 AI。
   - 自动 AI 仍会先走版本回填、自动分析条件检查、Agent/Provider 校验和通知链路。

3. **任务日志补齐 TID / trace_id**
   - 系统任务与 QTR 任务的执行日志现在会持久化 `trace_id`。
   - 任务日志列表新增 **TID** 列和搜索条件，详情页也会展示完整值。
   - 导出任务日志时会同时导出 TID，便于离线排查同一次执行链路。

## 影响范围

- 工单同步自动化
- 工单日志拉取
- 工单自动 AI
- 系统任务日志 / QTR 任务日志

## 使用说明

- 如果发现某张工单被再次编辑，但自动日志没有重新创建记录，先检查自动化审计中是否显示“复用成功日志”；这是当前的预期行为。
- 如果只想追查某一次自动任务链路，请在任务日志页按 **TID** 搜索。
