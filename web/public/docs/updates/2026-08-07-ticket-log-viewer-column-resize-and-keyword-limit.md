# 2026-08-07 工单日志查看器列宽拖拽与搜索关键字上限调整

## 本次调整

1. 搜索结果列表移除独立“时间”列，避免与日志内容开头的时间重复展示。
2. “日志内容”列表头新增时间排序箭头；点击后仍按日志时间升序或降序排序，不改动后端搜索结果顺序接口。
3. 搜索结果虚拟表格支持自定义拖动列宽，可分别调整文件、行号和日志内容列宽；操作列保持固定宽度。
4. 日志搜索关键字上限从 10 提升到 20；每个关键字最多 200 字符、结果条数上限保持不变，日志高亮关键字也同步提升到 20 个，并按关键字轮换不同颜色。

## 使用说明

### 调整列宽

- 将鼠标移动到“文件”“行号”或“日志内容”表头右侧的细分隔条上。
- 按住后左右拖动，即可实时调整当前列宽。
- 关闭弹窗或重新打开新的日志记录后，列宽会恢复默认值。

### 时间排序

- 点击“日志内容”表头中的箭头，可在升序和降序之间切换。
- 排序依据仍然是每条命中日志中解析出的时间值；无法识别时间的行会固定排在已识别时间之后。

### 搜索关键字上限

- 搜索输入框现在最多提交 20 个关键字。
- 关键字仍支持英文逗号、中文逗号、分号或换行分隔。
- 每个关键字仍会在提交前裁剪到 200 个字符。
- 高亮关键字输入框现在也最多保留 20 个，支持在上下文区域按关键字轮换不同颜色；输入过多时仍会按顺序截断。

## 影响范围

- 工单详情页日志查看弹窗。
- 工单日志拉取记录管理页日志查看弹窗。
- 旧版复用 `useLogViewer.js` 的页面也会同步采用新的搜索关键字上限。

## 验证建议

1. 搜索 15~20 个关键字，确认前后端都能正常提交并返回结果。
2. 点击“日志内容”表头箭头，确认排序方向切换正常。
3. 拖动列宽后滚动结果列表，确认虚拟表格没有明显卡顿或错位。
