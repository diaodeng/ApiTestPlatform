# 2026-06-08 工单角色拆分说明

## 本次变更

1. 工单主表新增 `1线人员` 和 `内部负责人` 两组结构化字段，用于区分“谁接到用户反馈工单”和“内部模块负责人”。
2. 工单新增/编辑弹窗增加这两个角色的维护入口，避免这些信息继续挤在单一“负责人”字段里。
3. 工单详情概览区同步展示 `当前处理人`、`1线人员` 和 `内部负责人`，便于核对责任分工。
4. 服务端启动时会自动检查并补齐旧库中的新字段，降低存量环境升级成本。
5. 工单列表页补充了这三类角色的筛选与展示列，方便在列表层面直接定位责任人。

## 语义约束

1. `current_assignee` 继续表示当前处理人，负责工单流转、指派和状态处理。
2. `first_line_assignee` 表示一线接单人员，通常对应用户反馈回来的第一责任人。
3. `internal_owner` 表示内部模块/工单负责人，可用于内部协同和模块归属展示。
