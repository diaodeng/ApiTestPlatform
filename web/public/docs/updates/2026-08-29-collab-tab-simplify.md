# 协同/AI 标签页简化调整

- 变更日期：2026-08-29
- 变更范围：工单管理 → 工单详情弹窗（协同/AI tab）。

## 变更内容

- 移除协同/AI tab 顶部独立的 **发起AI分析** 按钮：在该 tab 提交消息（`runAi=true`）与原按钮一样都会调用后端 AI 分析任务创建接口，日常场景二者等效，保留提交消息即可发起分析；需要配置日志时间窗等高级参数的完整版发起弹窗仍保留在概览 tab。
- **任务历史** 按钮移入消息表单第一行（角色、类型、发起AI开关所在行）。
- 消息表单区域由 16 栅格调整为整行铺满（原右侧 8 栅格为相似工单卡片，移除后不再留白）。
- 消息表单布局调整：**版本** 与 **Agent** 同一行，**Provider** 与 **模型** 同一行，减少表单纵向长度。
- 附件 JSON 输入区放入默认收起的 **高级选项** 折叠面板，正常场景只需填写内容后提交。
- 消息流只展示 AI 分析链路相关消息（类型为 `question` 提问、`analysis` AI 分析结论、`conclusion` 结论）；快照生成（`snapshot`）、外部同步导入（`sync_import`）、事件动作、系统建单等系统类消息不再显示在本区域。
- 消息带附件时不再直接平铺 JSON 内容，改为在消息行显示 **详情** 按钮，点击弹窗查看格式化 JSON 详情。

## 使用说明

- 正常流程：进入协同/AI tab → 填写消息内容 → 点击 **提交消息**，系统自动发起 AI 追问分析，分析结果以 AI 消息出现在消息流中。
- 需要附加日志片段、traceId 等结构化数据时，展开 **高级选项（附件 JSON）** 填写合法 JSON。
- 查看历次分析任务点击第一行的 **任务历史** 按钮。
- 查看某条消息的完整 JSON 附件（如 AI 分析原始结果），点击该消息右上角的 **详情** 按钮。

## 技术说明

- 前端组件：`web/src/views/ticket/components/detail-tabs/TicketDetailCollabTab.vue`（表单布局、折叠面板、消息过滤、详情弹窗）、`web/src/views/ticket/components/TicketDetailWithList.vue`（协同 tab 不再监听 `run-ai` 事件）。
- 后端未改动：提交消息仍走 `POST /ticket/{ticket_id}/messages`（`runAi=true` 时后端内部调用 `TicketAiAnalysisService.create_analysis_task_services`，与“发起AI分析”弹窗最终提交的 `POST /ticket/{ticket_id}/ai-analysis` 为同一创建逻辑）。
- 消息过滤在前端完成，接口返回契约不变；其他页面（如概览、历史）不受影响。

## 注意事项

- 提交消息默认触发 AI 分析（沿用原表单“发起AI”开关默认开启的行为）；AI 追问提交失败时会有警告提示，消息本身仍会保存。
- 如果消息流看起来“少了”同步导入、快照等记录，属于本次调整的预期行为，请到对应区域查看。
