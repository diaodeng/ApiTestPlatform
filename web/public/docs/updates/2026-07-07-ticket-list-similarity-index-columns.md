# 2026-07-07 工单列表增加相似度列和序号列

## 问题
工单列表缺少相似度分数显示，且没有序号列。

## 解决方案
在工单列表中增加两个新列：
1. **序号列** - 显示行号，位于表格最左侧
2. **相似度列** - 显示自然语言搜索的相似度分数（百分比格式）

两列都支持在列设置中配置显隐。

## 改动文件

### 1. `web/src/views/ticket/hooks/useTicketList.js`
- 在 `ticketColumnOptions` 中添加 `index`（序号）和 `similarityScore`（相似度）列配置
- 修改 `handleNaturalSearch` 函数，传递过滤条件参数给后端

### 2. `web/src/views/ticket/index.vue`
- 添加工号列模板（使用 `type="index"`）
- 添加相似度列模板（显示百分比格式，如 `85.3%`）

## 列配置
- 序号列：默认隐藏，可在列设置中开启
- 相似度列：默认隐藏，可在列设置中开启
- 两列都不是 required，用户可以自由配置显隐

## 相似度显示
- 当有 `similarityScore` 字段时，显示为百分比（如 `85.3%`）
- 当没有该字段时，显示 `-`
- 相似度分数来自后端自然语言搜索接口返回的 `similarityScore` 字段

## 验证
- 需要重启前端开发服务器
- 在列设置中应该能看到"序号"和"相似度"两个新选项
- 自然语言搜索后，相似度列会显示匹配分数
