# 2026-08-08 凭证新增表单增加字段提示

- 凭证新增/编辑弹窗各字段标签旁增加问号提示按钮（PromptButton 组件），覆盖以下字段：
  - 凭证类型：各类型的用途和填写内容对照表
  - 更新方式：各方式的适用场景和自动刷新支持情况
  - Cookie：填写格式和示例
  - Header 名称/值：含义，强调一个凭证只对应一组 Header
  - Token 各字段：Header 名称、值前缀、Token 值各自的含义和拼接逻辑
  - 其他敏感字段 JSON：用途说明、示例和请求模板引用方式
  - 登录用户名/密码：来源（用户自行填写）和 `${secret.xxx}` 引用方式
  - OTP 类型：各类型说明和自动刷新支持情况
  - TOTP 密钥：说明和示例
  - 请求 Header / 查询参数 / JSON 请求体 / 表单请求体：格式和占位符说明
  - 响应提取规则：详细说明凭证字段（target）与凭证类型的对应关系，来源（source）的格式规范（json:/header:/cookie:/cookies），以及关键约束（字段名必须与 secret 字段名一致、Set-Cookie 自动合并等）
  - 自动刷新：说明和间隔设置建议
  - 并发策略：三种策略的说明
  - 允许域名：格式、通配符支持
