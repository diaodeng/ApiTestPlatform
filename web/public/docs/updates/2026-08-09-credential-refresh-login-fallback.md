# 2026-08-09 凭证刷新失败自动登录兜底

- HTTP 刷新凭证在同时配置 `login_url` 时，会先按刷新接口续期；当刷新失败时，系统会自动执行登录，再用登录得到的新凭证重试刷新。前端在 `http_refresh` 模式下会同时暴露“刷新接口”和“兜底登录接口”配置入口，便于直接维护两段链路。
- 该兜底仅作用于 `http_refresh`，不会改变 `http_login` 的单次登录语义。
- 登录、刷新和重试请求都会继续携带当前凭证中的附加 Header、附加 Cookie 和模板变量。
- 新增定向测试覆盖刷新失败后的登录兜底、登录成功后再次刷新，以及 `refresh_credential()` 的分支调用。
