# 2026-09-12 桌面客户端 mitmproxy 页面体验优化（证书引导/信息栏精简/窗口最大化）

## 背景

用户反馈四点：①首次使用提示"找不到证书"但不知道原因；②页面顶部展示的代理端口/Web 端口与设置弹窗重复；③"当前模式说明"独立占一行较占空间，"当前运行方式"藏在其中不直观；④启动窗口默认 1200x800，笔记本屏幕显示不全。

## 变更内容（均在 `ui/pages/mitmproxy_page.py`、`main.py`）

1. **证书缺失引导提示**：证书状态消息包含"未找到"时自动追加——"首次使用请先点击「启动」运行一次代理，证书文件会在首次启动时自动生成，之后再安装证书"。已信任/其他状态不受影响。
2. **移除顶部端口展示**：信息栏不再显示代理端口与 Web 端口（设置弹窗中已有，且端口属低频查看项）。
3. **模式说明收纳为问号按钮**：删除独立占一行的"当前模式说明"label，信息栏右侧新增「?」按钮（带 tooltip），点击弹窗展示完整的当前模式说明与当前运行方式；文案组装逻辑保留（`_update_mode_hint` → `_mode_hint_text`），弹窗标题"当前模式与运行方式"。
4. **启动最大化**：`main.py` 中 `window.show()` 改为 `window.showMaximized()`，启动即铺满当前屏幕，适配笔记本小屏。

## 验证

- 离屏自测 10 项全过：端口标签移除、问号按钮存在、启动方式仍显示、弹窗文案含模式说明与运行方式、独立说明标签已移除、证书缺失提示追加、缺失时安装按钮禁用、已信任状态无追加提示、已信任状态按钮可用。
- `py_compile` 通过；ruff 与基线一致（13 处存量，零新增）。
- 未执行：真实窗口最大化效果需在带屏环境肉眼确认（offscreen 下无法验证布局观感）。

## 剩余风险

- 启动最大化对所有用户生效；习惯固定小窗口的用户需手动还原（未做"记住上次窗口状态"）。
- 证书提示依赖消息文案中的"未找到"关键字判断，若上游 `mitmproxy_cert` 文案变更需同步。
