# 2026-08-25 自动化结果通知

- 工单同步后的自动拉日志、日志拉取后的自动 AI 分析支持统一配置结果通知。
- 可选择已有推送配置，并独立控制成功和失败/跳过是否推送。
- 通知模板支持工单号、商家、门店、阶段、状态、失败原因和详情等变量；配置页面会展示变量含义。
- 自动 AI 提交失败时，服务返回的 `result.message` 同时写入通知“原因”和工单时间线 `auto-ai:failed` 事件；事件单独提交，避免线程会话关闭回滚。
- 补充生产部署注意事项：`start.sh` 下 FastAPI 与 Celery Worker 为不同进程，Agent WebSocket 连接不能依赖进程内字典跨进程共享；跨进程派发需后续接入消息网关或内部 HTTP 中转。
- 自动化任务创建时会保留通知配置快照，避免后续修改配置影响已启动任务。
