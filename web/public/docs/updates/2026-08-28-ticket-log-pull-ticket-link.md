# 日志拉取记录支持跳转工单详情

- 变更日期：2026-08-28
- 变更范围：工单管理 → 日志拉取管理列表页。

## 变更内容

- 日志拉取记录列表的「关联工单」列新增跳转能力：记录存在关联工单时，点击工单编号/标题区域会在新标签页打开对应工单详情页。
- 无关联工单的记录保持原有展示，仍显示“-”，不可点击。
- 跳转地址复用系统内已有的工单详情路由（`/ticket/detail/{ticketId}`），不改变任何后端接口契约。

## 使用说明

- 进入「工单管理 → 日志拉取管理」页面。
- 在列表中找到带「关联工单」信息的记录。
- 点击工单编号/标题区域，浏览器会在新标签页打开工单详情。

## 注意事项

- 需要当前账号拥有工单详情页的访问权限；无权限时跳转后仍受系统路由权限控制。
