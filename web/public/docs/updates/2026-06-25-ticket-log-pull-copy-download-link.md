# 日志拉取下载链接复制

## 背景

工单详情页日志拉取列表的“下载原始包”和日志拉取管理页的“下载日志”此前主要通过前端按钮触发下载，用户无法直接复制原始日志包地址到邮件或 IM。

## 变更

1. 工单详情页日志拉取列表“原始压缩包”列新增“复制链接”入口：
   - “下载原始包”保留原有打开外部 `commandResultUrl` 的行为。
   - “复制链接”复制外部原始压缩包地址，便于直接粘贴到邮件。

2. 日志拉取管理页“操作”列新增“复制链接”入口：
   - 有 HTTP 归档地址时复制归档地址。
   - 没有归档地址但有原始压缩包地址时复制原始压缩包地址。
   - 本地或 FTP 归档场景复制系统下载接口地址，并提示访问时需要当前系统登录态。

3. 前端复制逻辑优先使用浏览器 Clipboard API，不支持时回退临时输入框复制，避免 HTTPS/浏览器能力差异导致无法复制。

## 验证

- 已执行 `npm run build:prod`，构建通过；仅保留既有 `config.js`、`eval` 和 chunk 体积提示。
