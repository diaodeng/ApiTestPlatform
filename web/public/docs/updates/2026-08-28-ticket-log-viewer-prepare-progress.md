# 工单日志查看准备进度复用

## 变更内容

- 工单详情页和日志拉取记录管理页打开日志前，先读取当前记录的准备状态。
- 已处于准备中或下载中的记录直接等待原任务，不重复发起日志准备/下载请求。
- 列表操作区用环形进度显示准备或远程下载状态；关闭弹窗后仍会继续显示。
- 离开详情页、刷新或重新进入管理页后，前端从后端进度缓存恢复下载百分比。

## 注意事项

进度按“工单 ID + 日志拉取记录 ID”隔离，后端默认保留约 30 分钟。进度缓存过期后，系统会重新检查实际日志文件并决定是否需要准备。
