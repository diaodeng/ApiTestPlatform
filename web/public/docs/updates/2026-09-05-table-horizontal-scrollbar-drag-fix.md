# 2026-09-05 - 表格横向滚动条拖拽修复

## 用户可见变化

- 修复工单相关页面（工单列表、日志拉取记录、工单详情等）表格底部横向滚动条鼠标拖动不灵敏的问题：此前鼠标横向拖动很远，表格内容只移动一点，表格越宽越明显。
- 修复后横向拖动滚动条时，表格内容与鼠标移动距离按实际比例同步滚动；shift+鼠标滚轮横向滚动行为不变。
- 纵向滚动条拖拽行为不变。

## 变更原因

- 项目使用的 Element Plus 2.10.0 存在官方缺陷：滚动条拖拽计算中横向方向误用纵向的 scrollHeight 作为换算基数，导致横向拖动被压缩为约 scrollHeight / scrollWidth 的比例。
- 官方在 2.10.2 修复该问题（changelog 条目 "Components [scrollbar] horizontal scroll drag invalid"，PR #20953）。
- 本次将 element-plus 从 2.10.0 升级到 2.10.7（2.10.x 同 minor 的最新补丁版），同时获得 2.10.3 ~ 2.10.7 的其他修复（表格隐藏时宽度计算错误、下拉框 hover 异常滚动、滚动条容器尺寸变化处理等），无破坏性变更。

## 影响范围

- 仅升级前端依赖 element-plus 2.10.0 → 2.10.7，无业务代码改动。
- 全站使用 el-scrollbar 自绘滚动条的组件（el-table、下拉框等）横向拖拽均受益。
- 页面中自定义的滚动条样式覆盖（如日志拉取表格常显横向滚动条、加高滚动条、thumb 最小宽度）不受影响。

## 注意事项

- 如本地 node_modules 为旧版本，请重新执行 `npm install` 后再启动开发服务。
- 若后续升级到 2.11.x 及以上，滚动条 thumb 尺寸计算会进一步优化（2.11.1），属增强性质，非必须。
