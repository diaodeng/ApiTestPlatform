# 工单日志查看器搜索结果虚拟表格优化

## 背景

日志查看弹窗中的搜索结果列表在命中数量较大时，会因为普通表格的全量渲染和滚动计算出现卡顿，影响继续定位日志的效率。

## 调整内容

1. 将 `web/src/components/ticket/LogViewerDialog.vue` 中的搜索结果列表从普通 `el-table` 切换为 `element-plus` 的 `el-table-v2` 虚拟表格。
2. 保留原有交互：点击结果行继续加载上下文，“在此文件搜索”继续按当前文件收敛搜索范围。
3. 结果表格宽高继续跟随弹窗当前展示模式计算，只把渲染容器替换成虚拟表格，不调整后端接口和结果结构。

## 影响范围

- 仅影响共享日志查看组件 `LogViewerDialog.vue`。
- 工单详情页和日志拉取记录管理页共用该组件，因此都会获得这次前端性能优化。

## 验证要点

1. 打开命中量较多的日志拉取记录，确认搜索结果列表可以平滑滚动。
2. 点击任意结果行，确认上下文区域仍能正常加载。
3. 点击“在此文件搜索”，确认文件范围切换后仍能继续搜索。
4. 分别在普通、全屏和最小化模式下切换，确认结果区显示位置和高度没有异常。
