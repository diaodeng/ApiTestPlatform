# 工单日志搜索结果预览截断

## 背景

日志搜索命中行可能包含整段 JSON、请求体或配置内容。此前接口会将完整命中行直接返回给前端表格；命中数量多且单行很长时，响应体、浏览器 JSON 解析和 Vue 表格渲染会出现明显卡顿。

## 实现

`POST /ticket/logs/search` 现在仅返回每条命中行的前 500 个字符，并增加：

- `contentLength`：原始命中行字符数。
- `contentTruncated`：命中行是否超过 500 字符。

前端搜索结果表格对截断内容显示省略号。用户点击结果后仍以 `file + line` 调用 `/ticket/logs/context`，获取完整的命中行和上下文，因此诊断能力不受影响。

## 边界

截断发生在搜索业务完成后的接口响应转换阶段，不影响关键字匹配、命中行定位或异常提取等使用完整文本的服务端逻辑。
