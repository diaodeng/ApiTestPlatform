# 2026-09-13 客户端 Agent 页服务选择改为名称下拉并恢复 server_list 存储语义

## 变更背景

- Agent 页顶部「服务地址」为可自由输入的地址框（datalist 提示），直接展示 `ws://...` 连接地址，不符合"按名称选服务"的使用习惯。
- pywebview 迁移时把 `server_list` 的映射方向写反：后端 `save_server` 存成 `{名称: 地址}`，而存量配置（与旧 PySide6 版一致）是 `{地址: 名称}`，导致服务器管理弹窗两列显示颠倒、下拉提示内容错乱。
- 连接过程中仍可修改服务器选择，存在运行中切换目标的误操作风险。

## 变更内容

### 前端 `ui_web/static/js/pages/agent.js`

- 顶部「服务地址」输入框（含 datalist）移除，替换为「服务」下拉框：选项显示服务名称（`server_list` 中该地址对应的名称，无名称时兜底显示地址），`value` 存地址。
- 未选择时显示占位项（"请选择服务器" / "请先在服务器管理中添加"）；历史遗留的当前地址不在列表中时兜底追加一个地址选项，避免选中值丢失。
- 连接状态下（连接中/运行中/断开中）下拉框禁用，停止后才可修改（对齐旧版 `server_combo.setEnabled(not running)`）。
- 服务器管理弹窗：列表按"服务名称 / 服务地址"两列展示（修正此前颠倒），选中行与新增/修改/删除均按服务地址标识；保存后直接使用返回配置刷新下拉。

### 后端 `ui_web/api/agent_api.py`

- `save_server(name, url, old_url)` / `delete_server(url)` 恢复旧版语义：`server_list = {服务地址: 服务名称}`，`current_server` 存地址；修改地址时若正是当前使用服务则 `current_server` 跟随新地址，删除当前服务时回退到剩余第一项。
- 未选择服务时启动连接的提示改为"请先选择服务器"。

### 服务 `services/agent_client_service.py`

- 开始连接的状态提示不再携带连接地址（改为"开始连接服务器..."），地址仅在应用日志中记录；界面顶部不再展示服务地址。

## 验证

- 后端冒烟（假配置类，不动真实配置）：新增、修改当前/非当前服务、删除当前服务后 `current_server` 的跟随与回退、重名地址与参数缺失拒绝，全部符合预期。
- `node --check` 通过；`grep` 确认无 `serverInput`/`datalist` 残留引用。

## 备注

- 交互约束：连接中不可切换服务器；如需切换，先「停止」再选择。
