# 2026-09-12 插件安装目录支持用户自定义（默认程序目录）

## 背景

插件运行数据目录上一版改为固定 `%LOCALAPPDATA%` 以规避构建产物污染问题；用户希望恢复"绿色便携"语义——**默认安装在程序（exe）所在目录**，同时支持在插件页面自定义安装路径，修改时给出影响提示并由用户决定是否迁移。

## 变更内容

1. **配置项**（`model/config.py` + `do/config.py`）：`PluginConfigModel` 新增 `install_dir`（空 = 默认目录）；`PluginsConfig` 配置文件路径改为 frozen 感知——打包态固定到 exe 目录下 `storage/data/config_plugins.json`（原 cwd 相对路径会导致 helper 子进程读不到自定义目录）。
2. **动态根目录**（`plugins/manager.py`）：
   - `get_plugin_root()`：读取配置的 `install_dir`，为空回退默认目录（打包态 = exe 目录，开发态 = client_new 目录）；`plugin_dir()` 改为动态解析；
   - 新增 `set_install_dir(new_dir, migrate)`：校验绝对路径、保存配置、按需把当前根目录下已装插件搬到新根目录；传空恢复默认；
   - `_legacy_plugin_roots()` 迁移链：启动时自动把历史位置（LOCALAPPDATA、旧版 exe 目录）的插件搬到当前根目录，覆盖"升级版本"与"改回默认目录"两个场景。
3. **插件管理对话框**（`ui/dialogs/plugin_manager_dialog.py`）：新增"安装目录"行（输入框 + 浏览 + 保存）；路径变化时弹三选影响提示——**迁移已装插件 / 仅保存 / 取消**，影响说明包含"默认目录随程序目录可整体拷贝、自定义目录需自行保证可用、位于构建输出目录内时重打包前需停 WinDivert 驱动"。

## 验证

- 离屏自测 10 项全过：默认根目录指向程序目录、切换自定义目录并迁移（插件搬迁 + 旧目录清空）、相对路径拒绝、恢复默认并迁回、对话框输入框与当前根一致；
- `py_compile` 通过；ruff 较基线 +3 均为配置读取/目录保存的防御性盲捕获（与插件隔离风格一致）。

## 剩余风险

- 默认目录回到程序目录后，"在构建输出目录内运行客户端并装插件 → 重打包时 WinDivert.sys 被锁定"的场景会重新出现（影响提示与文档已说明处理办法：`sc stop WinDivert` 或先迁移目录）；
- 修改安装目录后需重启客户端生效（与插件挂载机制一致）；影响提示弹窗为三选一交互，仅保存（不迁移）时旧目录插件将不再生效，需用户自行理解——已在提示文案中说明。
