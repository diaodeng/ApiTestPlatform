# 2026-07-04 工单日志链接与 AI 默认选择修复

## 背景

工单日志拉取列表只展示数据类型，缺少实际拉取参数，排查时无法直接判断本次按日期还是按数据库路径拉取。归档地址和原始压缩包此前使用“下载/复制”按钮组合，和详情顶部外部链接交互不一致。

发起 AI 分析和协同/AI 表单中，Agent、Provider、追加提示词在部分场景没有按配置项自动选中；用户手动修改后，下次打开也不会沿用上次选择。

## 变更

1. 工单详情页日志拉取列表新增“拉取参数”列：
   - 日志类型显示 `时间：modifyTime`。
   - 数据库类型显示 `路径：path`。

2. 日志拉取管理页同步显示“拉取参数”“归档地址”“原始压缩包”：
   - “下载日志”和“复制链接”按钮入口收敛到两列链接上。
   - 归档地址左键打开或下载；右键复制可访问链接。
   - 原始压缩包左键打开外部地址；右键复制外部地址。

3. 链接规则统一下沉到 `web/src/views/ticket/logPull.shared.js`：
   - HTTP 归档直接使用原始 URL。
   - 本地/FTP 归档复制系统下载接口地址，访问时仍依赖当前系统登录态。
   - 本服务归档左键下载仍走已有 axios 下载逻辑，避免普通 `<a>` 缺少 `Authorization` 请求头。

4. 新增 `useTicketAiPreference.js` 管理工单 AI 前端偏好：
   - 默认值优先级：用户手动选择记忆 > 工单自动化配置 > 最近一次 AI 分析。
   - 发起 AI 分析弹窗记忆 Agent、Provider、追加提示词。
   - 协同/AI 表单记忆 Agent、Provider。
   - Provider 配置绑定 Agent 时，未手动指定 Agent 的情况下会自动带入绑定 Agent。

## 影响范围

- 工单详情页日志拉取列表。
- 日志拉取记录管理页。
- 工单详情页“发起AI分析”弹窗。
- 工单详情页“协同/AI”消息表单。

## 验证

- 已执行 `npm run build:prod`，构建通过。
- 构建仅保留既有 `config.js`、`eval` 和 chunk 体积提示。
