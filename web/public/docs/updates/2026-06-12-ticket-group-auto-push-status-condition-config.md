# 2026-06-12 群消息自动推送状态条件改为可视化配置

## 背景

工单群消息自动推送原先在后端 `TicketSyncService._send_auto_group_message_once` 中写死了状态条件：

- `2. 1.5线处理`
- `3. 待产研处理`
- `4. 产研处理中`

当业务状态策略调整时，需要改代码才能生效，不便于日常运维配置。

## 本次改动

1. 新增配置项：`groupPush.autoPushStatuses`。
2. 配置页“工单群消息推送”新增“自动推送状态条件”可视化多选输入（支持自定义状态文本）。
3. 自动推送时改为读取 `groupPush.autoPushStatuses` 做状态判断，不再使用硬编码。
4. 默认值保持历史行为（上述三种状态），确保升级后行为一致。
5. 手动推送链路不使用该条件，不受影响。

## 生效范围

1. 外部推单后的自动群推送（`external_sync`）。
2. 远端拉取后的自动群推送（`remote_pull`）。
3. AI 任务完成后的自动补发群推送。

以上三条都走 `_send_auto_group_message_once`，所以都会统一按该配置判断。

## 使用说明

1. 在“工单同步自动化配置 -> 工单群消息推送 -> 自动推送状态条件”中维护状态列表。
2. 只有工单 `status` 命中列表时，自动推送才会执行。
3. 若清空状态列表，则表示“不按状态限制”。
