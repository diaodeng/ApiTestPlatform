# 日志内存分析全面升级：搜索管道引擎、图表日志双向联动、资源曲线独立入口

- 变更时间：2026-09-01
- 影响模块：工单日志查看器 - 内存分析、日志拉取记录管理页

## 变更内容

1. **扫描引擎升级**：内存分析扫描层从自研逐行扫描切换为复用日志搜索管道（`LogService.search`，rg 流式优先，缺失 rg 自动降级 Python，保留既有内存/并发/字节数保护）。进度按文件粒度推送，不再提供单文件内行级百分比。
2. **数据点携带行号与 epoch**：每个数据点新增 `line`（命中行号）与 `epoch`（本地时间 epoch 秒）；结果新增 `totalHits / parsedCount / skippedLineCount` 统计，命中但解析失败的行跳过并计数，不中断分析；解析成功点数达 20000 硬上限即停止扫描并标记截断。
3. **布局修复**：日志查看弹窗内容区支持纵向滚动、搜索工具栏吸顶；内存分析面板支持"最小化/展开"；点击日志行时内存面板自动最小化，解决曲线展开后日志详情被顶出可视区看不到的问题。
4. **图表 ↔ 日志双向联动**：
   - 点曲线数据点 → 直接打开该点对应日志行的上下文（点自带精确文件+行号），内存面板自动最小化；
   - 点搜索结果日志行 → 曲线上按时间就近画红色虚线标记（标注行号）；
   - 内存分析跟随当前搜索的文件范围过滤。
5. **资源曲线独立入口（日志拉取记录管理页）**：操作列新增"曲线"按钮，打开独立弹窗：上半部分为该记录全局资源曲线，下半部分为数据点列表（分页，含时间/文件/行号/CPU/内存/线程）；点击曲线点或列表行打开完整日志查看器并跳转对应行上下文。

## 说明

- 日志时间不带时区，曲线横轴按服务器本地时间展示。
- 曲线渲染使用 ECharts lttb 采样，数据点在返回前已降采样到 2000 点，2 万原始点约 2~3MB JSON。
