# 指定工单手动自动化补跑

## 新增内容

- 在“工单同步配置 → 飞书多维表格主动拉取”中新增“指定工单手动自动化”入口。
- 支持输入一个精确工单号，并选择“查询多维表格”或“使用数据库快照”。
- 查询多维表格模式可在定时主动拉取关闭时使用；本次查询只按工单号筛选，不使用常规筛选公式和时间窗口。
- 数据库快照模式只重放同步后的自动化，不会重新入库或覆盖当前工单字段。

## 使用影响

- 两种模式都沿用既有 `bitable_pull` 自动化场景及自动化关注范围，AI、日志、分类、向量和通知等开关仍按当前配置生效。
- 多维表格模式要求飞书连接、表格和字段映射配置完整；同一工单号必须唯一精确匹配，避免误同步。
- 本次功能不修改原有定时任务，也不改变正常主动拉取流程。
