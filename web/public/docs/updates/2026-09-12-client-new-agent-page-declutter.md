# 2026-09-12 桌面客户端 Agent 页面信息精简（连接设置弹窗/去掉冗余地址行）

## 背景

用户反馈：继 mitmproxy 页面信息栏精简后，其他页面也存在类似的初始显示冗余问题；其中 Agent 页面最突出——①顶栏服务器地址下方又用一整行展示 MAC/连接地址/状态信息，连接地址与上方地址下拉框重复；②服务器选择后面平铺了最大发送、自动重试、重试次数、重试间隔、断线重连、低频间隔共 6 个配置控件，顶栏一行在小屏下溢出，信息过多。

已离屏截图逐页核查 6 个页面（Agent/POS/SQLite/mitmproxy/日志/关于）：其余页面顶栏均为高频操作项、无重复展示，无需改动；问题集中在 Agent 页。

## 变更内容

均在 `ui/pages/agent_page.py`、`ui/dialogs/agent_connection_setting_dialog.py`（新增）：

1. **去掉底部冗余信息行**：移除 MAC 与"连接地址"label（连接地址 = 地址下拉框 + /MAC，完全重复）。MAC 改为页面内部字段记录（`set_local_mac`），控制器接口不变；"状态信息"label 保留为独立一行，继续承载连接过程动态反馈。
2. **新增「连接设置」弹窗**（`AgentConnectionSettingDialog`）：收敛"单条消息上限 / 自动重试 / 重试次数 / 重试间隔 / 低频永续重连 / 低频间隔"6 项配置；按主开关联动——未勾选自动重试时重试次数/间隔禁用，未勾选低频永续重连时低频间隔禁用。弹窗内附参数语义提示。
3. **顶栏精简**：操作栏新增「连接设置」按钮（服务器管理与浏览器设置之间）；配置行仅保留 状态徽标 / 地址 / 别名 / 显示日志，1200px 宽度下不再溢出。
4. **数据链路不变**：页面保留发送/重连配置的值副本，`_collect_data`/`apply_config` 输出输出键完全一致，配置保存与 controller 链路无契约变化；弹窗打开期间配置被刷新时同步弹窗值（与浏览器设置弹窗同一模式）。默认发送上限兜底值与配置模型对齐为 5KB。
