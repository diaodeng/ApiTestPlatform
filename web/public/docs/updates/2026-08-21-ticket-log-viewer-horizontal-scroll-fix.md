# 工单日志查看器横向滚动修复

## 修复内容

修复日志查看器上下文区域在关闭“换行”时无法左右查看较长日志内容的问题。

现在关闭“换行”后，日志上下文保留单行展示，内容超出可视区域时可以使用上下文区域底部的横向滚动条查看完整的已加载内容。开启“换行”后，日志会按可视区域折行，便于快速浏览。

## 超长行说明

对于超过上下文读取限制的日志行，查看器仍会先展示截断摘要。点击“展开完整内容”可在独立阅读区域中查看完整文本，并继续使用全宽、全屏和复制功能。

本次修复仅恢复上下文区域的横向浏览，不改变日志搜索、上下文长度保护或按需读取完整行的行为。
