# 门店配置任务文件存储设计（规划）

> 本文记录门店配置自动化的设计规划，当前尚未上线对应功能，不能直接用于生产执行。

## 设计方向

门店配置任务会复用现有 Web 录制、浏览器执行和 Agent 能力，但任务编排、文件资源、运行阶段和截图产物独立管理。

## 文件存储规划

首期考虑到服务端暂时没有可直接复用的通用资源存储，输入文件可以保存在执行 Agent 的受控本地目录。平台服务端仍会为每个资源生成并记录资源 ID、文件版本、大小、SHA-256、所属 Agent 和生命周期状态，任务通过资源 ID追踪文件，不把 Agent 机器的绝对路径作为任务配置。

后续支持 SFTP 作为可选存储方式。SFTP 会作为独立存储 Provider 设计，和 Agent 本地存储使用统一的资源 ID模型；实际使用哪一侧访问 SFTP，会在资源元数据中明确。

## 与 Web 录制的关系

现有 Web 录制数据用于整理可复用的操作模板。配置任务再引用模板执行门店查询、配置核对、文件导入和截图取证。首期优先支持查询、截图和人工确认后的低风险操作，不默认开放无人值守生产写入。

## 当前边界

- 本文是设计规划，不代表文件上传、截图归档或 SFTP 功能已经实现；
- 不要把账号密码写入录制步骤、任务参数或文档；
- 不要把 Agent 本地绝对路径作为跨机器接口参数；
- 生产环境的配置修改仍应经过参数校验、预览、人工确认和修改后验证。

## 参考范围

这是内部设计规划，不是已上线的操作说明。功能真正落地后，会另行补充对应的用户使用说明、配置项、权限和常见问题。
