# 2026-08-23 - 工单模块通用提示词

## 用户可见变化

- 新增 **HRM → 模块通用提示词** 页面，可按模块编码维护跨项目复用的 AI 分析说明。
- 工单 AI 分析默认按“项目默认提示词 → 模块通用说明 → 项目模块说明”的顺序加载；用户追加模板和本次临时说明仍按原流程追加。
- 工单详情的 AI 分析区域可展开查看三层提示词是否命中及正文摘要。
- 修改、停用或删除模块通用说明只影响后续创建的分析任务，历史任务保留原提示词快照。

## 数据维护

- 模块通用说明按 `module_code` 全局唯一保存；相同编码跨项目复用，不合并项目模块实体。
- 上线前先执行只读模块编码盘点，处理项目内重复编码和首尾空格后，再执行项目内联合唯一索引。
- 详细使用方式见：[模块通用提示词使用说明](../module_common_prompt.md)。
