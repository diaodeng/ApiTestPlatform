# 2026-09-14 桌面客户端 Agent 页「显示请求/响应日志」勾选状态回显修复

## 背景

Agent 页勾选「显示请求/响应日志」后切换到其它页面再切回，勾选框显示为未勾选，但日志仍在输出——显示状态与实际行为不一致。

## 原因

勾选状态在 `change` 事件时已通过 `save_config` 持久化到后端配置 `show_logs`（日志输出由后端按该字段判断，所以切换页面后日志继续输出）；但前端页面每次挂载时勾选框硬编码为 `checkbox("显示请求/响应日志", false)`，`applyConfig()` 只回显了服务器下拉框，未回显该勾选框，导致重新进入页面显示未勾选。

## 变更内容

### `client_new/ui_web/static/js/pages/agent.js`

- `applyConfig()` 中新增一行：用 `config.show_logs` 回显「显示请求/响应日志」勾选状态。该函数在页面初始化（`get_state`）、配置同步刷新、服务器保存后都会调用，覆盖所有重挂载路径。

## 验证

- `node --check` 语法检查通过；
- 未做 GUI 实机验证，建议启动客户端确认：勾选后切换页面再切回，勾选状态保持；取消勾选同样记忆并停止输出。

## 遗留与建议

- 无后端改动；其它页面（POS 启动配置等）已各自在加载时回显，未发现同类问题。
