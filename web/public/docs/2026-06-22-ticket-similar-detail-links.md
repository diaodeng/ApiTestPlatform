# 2026-06-22 相似工单详情跳转

## 背景

工单详情页的相似工单只展示编号、标题、相似度和根因摘要，排查时需要回到列表或外部系统手动查找，查看相似工单内容不方便。

## 改动

1. 新增隐藏前端路由 `#/ticket/detail/:ticketId`，URL 后拼接系统工单 ID 后可独立打开工单详情。
2. 独立详情页复用现有工单详情弹窗逻辑，进入页面后自动加载指定工单并打开全屏详情弹窗。
3. 工单详情页两个“相似工单”区域新增“系统详情”入口，点击后在新窗口打开当前系统详情页。
4. 相似工单若包含原飞书或外部详情链接，会额外展示“飞书详情”入口，继续复用已有外部详情链接解析规则。

## 影响范围

- 前端路由：新增只读详情入口，不新增后端接口。
- 工单详情页：相似工单卡片增加跳转动作，不改变相似度检索和详情数据结构。
