# 问题实例关联工单导出

## 功能说明
将选中的问题实例所绑定的工单导出为 Excel（.xlsx）文件。导出列可由用户手动选择，默认包含问题编号和问题名。

## 入口
- 问题实例管理页（`工单管理 → 问题实例管理`），工具栏中的 **导出工单** 按钮。
- 需要权限：`ticket:issue:export`。

## 使用方法
1. 在问题实例列表表格中勾选一个或多个问题实例（表格新增了复选框列）。
2. 点击 **导出工单** 按钮（未选择问题实例时按钮不可用）。
3. 弹出"导出问题实例关联工单"对话框，顶部提示已选择的问题实例数量。
4. 勾选需要导出的列（默认全选）。**问题编号**和**问题名**为必选列，不可取消勾选。
5. 点击 **导出** 按钮，浏览器将自动下载 Excel 文件。

## 数据组织方式
- 每个问题实例的每个关联工单占一行。
- 如果一个问题实例关联多个工单，则生成多行数据，每行的问题编号和问题名相同。
- 如果问题实例没有关联工单，也会生成一行数据（仅包含问题编号和问题名，工单字段为空）。

## 导出限制
- 单次导出上限：**10000 行**（所有选中问题实例的工单总数）。
- 超过上限时，系统会提示"当前匹配 N 条，超过单次导出上限 10000 条，请缩小选择范围后重试"。

## 常见问题

### Q: 导出按钮灰色不可点击？
A: 需要先在表格中勾选至少一个问题实例。

### Q: 导出按钮不可见？
A: 检查当前账号是否拥有 `ticket:issue:export` 权限。

### Q: 点击“导出工单”后没有看到下载？
A: 点击后会先显示“导出问题实例关联工单”对话框，请确认导出列后再点击对话框中的 **导出** 按钮下载文件。

### Q: 问题名和问题编号能否取消导出？
A: 不能，这两列是必选列，确保导出数据可以追溯到问题实例。
