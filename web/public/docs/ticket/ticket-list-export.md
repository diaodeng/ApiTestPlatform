# 工单列表导出

## 功能说明
将工单列表中的数据导出为 Excel（.xlsx）文件，支持按选中工单导出或按筛选条件导出，导出列可由用户手动选择。

## 入口
- 工单列表页（`工单管理 → 工单列表`），工具栏中的 **导出** 按钮。
- 需要权限：`ticket:ticket:export`。

## 使用方法

### 导出选中工单
1. 在工单列表表格中勾选需要导出的工单记录（支持跨页选择）。
2. 点击 **导出** 按钮。
3. 弹出"导出工单"对话框，顶部提示已选择的工单数量。
4. 勾选需要导出的列（默认全选），列名与 Web 页面列名一致。
5. 点击 **导出** 按钮，浏览器将自动下载 Excel 文件。

### 按筛选条件导出
1. 不勾选任何工单，或清空所有勾选。
2. 设置筛选条件（状态、项目、模块、关键字等）后点击搜索。
3. 点击 **导出** 按钮。
4. 对话框顶部提示"未选择工单，将按当前筛选条件导出全部匹配工单"。
5. 勾选导出列，点击 **导出**。

> **注意**：自然语言搜索后，如未勾选工单，系统将按当前页面可见的搜索结果导出，确保导出内容与页面展示一致。

## 配置项
| 参数 | 说明 | 默认值 |
|------|------|--------|
| 导出列 | 手动勾选需要导出的列 | 全部列 |
| 导出范围 | 有勾选时仅导出当前勾选的工单；否则按筛选条件导出 | - |

## 导出限制
- 单次导出上限：**10000 行**。
- 超过上限时，系统会提示"当前匹配 N 条，超过单次导出上限 10000 条，请缩小筛选条件后重试"。

## 常见问题

### Q: 导出按钮不可见？
A: 检查当前账号是否拥有 `ticket:ticket:export` 权限。

### Q: 导出后的 Excel 中文乱码？
A: 导出文件为 .xlsx 格式，使用 Excel 或 WPS 打开正常。如果用记事本打开会乱码，这是正常现象。

### Q: 自然语言搜索后导出的是全部工单还是搜索结果？
A: 自然语言搜索后，如果没有勾选工单，系统会导出当前页面可见的搜索结果，确保与您看到的一致。

### Q: 勾选一条工单后，为什么导出多条？
A: 勾选导出会严格按当前勾选的工单 ID 查询，不受列表默认每页条数影响；勾选一条时，Excel 只包含该条工单数据。

### Q: 导出结果为空？
A: 如果筛选条件没有匹配数据，系统会生成仅包含表头的 Excel 文件。
