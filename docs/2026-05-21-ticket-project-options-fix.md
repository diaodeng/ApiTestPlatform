# 2026-05-21 工单项目选项状态修复与公共项目管理说明

## 变更背景
- 用户反馈新增工单时项目/模块下拉为空。
- 实际 HRM 项目和模块列表有数据，但工单侧选项接口返回空。

## 根因
- 工单侧项目/模块选项、工单关联校验、导入解析里把“正常状态”写成了 `status == 0`。
- HRM 的正常状态值实际是 `QtrDataStatusEnum.normal = 2`，因此有效数据被全部过滤掉。

## 处理结果
- 工单项目/模块选项恢复复用 HRM 公共项目管理。
- 工单侧统一按 `QtrDataStatusEnum.normal.value` 过滤有效项目/模块。
- 导入与新增校验链路同步对齐，避免项目选项修复后别的入口继续空。

## 设计结论
- 公共项目管理是合理方案，工单只需要复用 HRM 的项目/模块主数据，不建议单独再建一套工单项目体系。
- 如果后续需要显式区分“工单项目”和“测试项目”，优先给 HRM 项目加结构化 `project_type`，不建议只靠自由标签长期筛选。

## 验证记录
- `cd web && npm run build:prod`：通过
- 后端变更后将补充 `ruff check` / `compileall` 验证。
