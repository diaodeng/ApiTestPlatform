# 2026-05-21 工单事件结构化数据 JSON 安全修复

## 变更背景
- 用户在“按时间点提交日志”时遇到 500 错误。
- 报错信息显示 `ticket_event.event_data` 中包含 `datetime`，数据库 JSON 字段无法直接序列化。

## 根因
- 工单事件写入链路把结构化数据原样塞进了 JSON 列。
- 日志拉取按时间点构造的 `event_data` 包含 `datetime`，触发 JSON 序列化失败。

## 处理结果
- 在 `TicketDao.add_event()` 统一对 `event_data` 做递归 JSON 安全转换。
- `datetime`、`date`、`time` 会转成 ISO 字符串，列表、元组、集合和字典会递归处理。
- 日志拉取服务的事件写入也改为统一走 `TicketDao.add_event()`，避免绕过该转换逻辑。

## 影响范围
- 工单导入事件。
- 工单日志拉取分析事件。
- 后续所有通过 `TicketDao.add_event()` 写入的结构化工单事件。

## 补充说明
- 日志拉取内容现在按时间范围完整入库，不再做静默截断；如果超过入库上限，会直接提示缩小时间范围。

## 验证记录
- 后端编译和 lint 将在本次修复后补跑。
